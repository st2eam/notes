# 胶片模拟

胶片模拟通过色彩响应、反差和明暗过渡塑造画面风格。富士的模拟方案来自胶片经验，也包含独立设计的数字风格，并非每一种都对应某款实体胶片；例如 CLASSIC CHROME 没有使用特定模拟胶片作为模型。参见 [富士 CLASSIC CHROME 说明](https://www.fujifilm-x.com/global/products/film-simulation/classic-chrome/)。

## 胶片特性与模拟边界

观察胶片感时，可分别比较色彩倾向、饱和度、阴影密度、高光过渡和颗粒。颗粒、褪色黑和暖色不是所有胶片共有的特征。拍摄曝光、光线、白平衡及后期处理也会影响效果，不宜把“胶片感”归结为一个滤镜。

机内模拟主要决定相机生成图像的呈现方式。保留 RAW 能给后期更多调整空间；JPEG 已包含渲染结果，后续调整的余地较小。选择方案时先确定画面目的，再比较同一场景的不同版本。

## 常用富士模拟方案

| 方案 | 主要观感 | 可尝试的场景 |
|---|---|---|
| PROVIA / 标准 | 均衡的色彩与反差 | 日常记录、通用起点 |
| Velvia / 鲜艳 | 饱和色彩和较强反差 | 风光、花卉，注意肤色与高光 |
| ASTIA / 柔和 | 较柔和的反差，保留鲜明色彩 | 人像、时尚 |
| CLASSIC CHROME | 克制的颜色和更明显的阴影对比 | 街拍、纪实 |
| ETERNA / 电影 | 柔和色彩与丰富阴影层次 | 希望保留柔和明暗的画面 |
| ACROS | 黑白层次、细节与颗粒表现 | 黑白人像、街拍 |

以上方案特性依据 [富士胶片模拟指南](https://www.fujifilm-x.com/en-gb/learning-centre/get-to-grips-with-film-simulation-modes/)，场景建议是应用思路。具体可用方案依机型而异。

“模拟方案”与“配方”要分开：配方还会组合白平衡偏移、高光、阴影、色彩和颗粒等设置。同名模拟套用不同配方，也会出现不同效果，参数应随光线和主体调整。

## Lightroom 中的应用思路

延续 [[影像/摄影/后期/后期处理|后期处理]] 的镜头校正、白平衡、曝光、曲线及 HSL 工作流，在细调前确定基础配置文件。

1. 导入 RAW 并检查相机是否被当前版本支持，在配置文件浏览器中查看 Camera Matching（相机匹配）组，若有对应模拟方案可将它作为起点。支持情况参见 [Adobe 相机支持表](https://helpx.adobe.com/camera-raw/desktop/dng-and-file-formats/camera-raw-plug-supported-cameras.html)。
2. 固定基础配置文件后校正曝光和白平衡，再微调曲线与颜色。配置文件与预设不同，预设可以同时保存多个调整项；不要把两者视为同一个滤镜。
3. 想做柔和复古效果，可适度控制反差与饱和度；是否抬黑位、添加颗粒应由参考图决定。ACROS 风格应先处理黑白颜色混合和层次，再判断颗粒量。
4. 以机内 JPEG 或参考图并排比较，并在肤色、高光和阴影分别检查。相机匹配配置文件是接近相机呈现的起点，不能保证逐像素重现机内处理或完整配方。

可将配置文件与风格调整存为预设，曝光、白平衡等与具体照片密切相关的设置则逐张校正。没有相机匹配配置文件时，使用其他基础配置文件手动接近目标效果，保留原始 RAW。参见 [Adobe 色调与配置文件说明](https://helpx.adobe.com/lightroom-classic/desktop/process-and-develop-photos/image-tone-color.html)。
