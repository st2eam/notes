## [JS异常](https://www.w3school.com.cn/js/js_errors.asp)

- try 语句使您能够测试代码块中的错误。

- catch 语句允许您处理错误。

- throw 语句允许您创建自定义错误。

- finally 使您能够执行代码，在 try 和 catch 之后，无论结果如何。
