# Go 简介

Go 是静态类型、编译执行的通用语言，提供垃圾回收、结构体、接口和语言级并发。包组织代码，工具链覆盖格式化、构建、依赖与测试。

## 特性与适用场景

适合网络服务、命令行工具与基础设施组件。gofmt 统一代码风格，编译器检查类型和未使用的导入；goroutine 由运行时调度，共享数据仍需同步。纯 Go 程序部署通常方便，使用 cgo 后还要考虑本地库与交叉编译限制。垃圾回收降低手动管理负担，但分配量仍会影响性能。

## 与其他语言对比

| 语言 | 主要差异 |
| --- | --- |
| Python | Go 提前检查类型，Python 更适合动态探索与脚本表达 |
| Java | Go 通过结构体与接口组合行为，没有传统类继承体系 |
| C++ | Go 有垃圾回收，底层资源控制与运行时约束不同 |

[[计算机/编程语言/Python/python多线程|Python 多线程]]介绍线程与锁；Go 的 goroutine 并非操作系统线程的一对一包装。

## 学习路径

先读 [[计算机/编程语言/Go/go语法|Go 语法]]、[[计算机/编程语言/Go/go数据类型|数据类型]]和[[计算机/编程语言/Go/go函数|函数]]，再学习接口与并发。用小型命令行项目串联模块、错误处理与测试，不依靠语言特性直接推断业务性能。
