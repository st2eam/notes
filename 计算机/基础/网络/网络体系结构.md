# 网络体系结构

## 定义

网络体系结构是各层及其协议的集合。教学中常用应用层、运输层、网络层、数据链路层和物理层的五层模型。

## 工作原理

每层处理一个范围内的问题，再通过接口向上层提供服务。

| 层次 | 主要职责 |
| --- | --- |
| 应用层 | 解释业务消息 |
| 运输层 | 提供进程之间的端到端通信 |
| 网络层 | 跨网络寻址与转发 |
| 数据链路层 | 在相邻节点之间传送帧 |
| 物理层 | 传送与识别比特对应的信号 |

OSI 七层模型与 [[计算机/基础/网络/体系与性能/TCP-IP 的共同网络层|TCP/IP]] 体系的层次划分不同。这里的五层模型是便于分析的综合表达。

## 示例

网线不通先检查物理连接，能连到服务器却收到错误响应则继续检查应用处理。

## 分层与接口

本层使用下层服务，为上层提供更适合它的抽象。对等层遵循同一协议，但实际数据要经过本机协议栈、通信媒体和对方协议栈。层次划分不意味着每层都需要重新实现所有功能。
