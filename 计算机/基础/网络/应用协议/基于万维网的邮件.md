# 基于万维网的邮件

## 定义

Web 邮件让用户通过浏览器界面使用邮箱服务。

## 工作原理

浏览器与邮箱 Web 服务之间可使用 [[计算机/基础/网络/HTTP|HTTP]] 或 HTTPS，但邮件服务器之间仍通过邮件投递协议交互。用户界面变化不代表底层邮件体系消失。
