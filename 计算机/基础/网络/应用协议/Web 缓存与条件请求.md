# Web 缓存与条件请求

## 定义

缓存保存资源副本以减少重复传输，条件请求在使用副本前检查其是否仍适用。

## 工作原理

未过期副本可按规则直接复用；需要验证时，可携带修改时间或实体标签等条件。未变化则返回相应状态而不重复发送完整消息体。代理缓存还可减轻出口和源站负担。

## 示例

服务器确认资源未变后返回 `304`，浏览器继续使用已有内容。
