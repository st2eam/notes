# DNS 缓存与资源记录

## 定义

[[计算机/基础/网络/域名系统DNS|DNS]] 缓存保存一定有效期内的查询结果；资源记录按类型保存不同含义的数据。

## 工作原理

资源记录按类型表达不同内容。

| 类型 | 对应信息 |
| --- | --- |
| A | IPv4 地址 |
| AAAA | [[计算机/基础/网络/IPv6|IPv6]] 地址 |
| CNAME | 别名 |
| MX | 邮件交换服务器 |
| NS | 域名服务器 |

[[计算机/基础/网络/IP与寻址/TTL|TTL]] 规定结果可以缓存多久。缓存降低了查询开销，但记录更新后，旧值可能仍在有效期内被使用。
