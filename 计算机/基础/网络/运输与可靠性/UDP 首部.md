# UDP 首部

## 定义

UDP 首部固定 8 字节，包含源端口、目的端口、长度和检验和四个字段。

## 工作原理

UDP 首部的四个字段各占 2 字节，总计 8 字节。

| 字段 | 含义 |
| --- | --- |
| 源端口 | 标识发送端的运输接口 |
| 目的端口 | 标识接收端的运输接口 |
| 长度 | UDP 首部与数据的总长度 |
| 检验和 | 检测传输中的部分差错 |

首部短可以降低开销，但报文大小仍受底层承载能力影响。[[计算机/基础/网络/UDP|UDP]] 自己不拆分应用报文，不代表 [[计算机/基础/网络/IP协议|IP]] 层永远不会对数据报分片。

## 示例

UDP 长度字段为 28，意味着应用数据为 20 字节，而不是 28 字节。
