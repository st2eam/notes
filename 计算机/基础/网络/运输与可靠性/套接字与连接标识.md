# 套接字与连接标识

## 定义

在地址表示意义上，套接字是 [[计算机/基础/网络/IP协议|IP]] 地址与端口号组成的通信端点；套接字 API 中则指操作系统提供的通信对象。

## 工作原理

一条 [[计算机/基础/网络/TCP|TCP]] 连接由本地 IP、本地端口、远程 IP、远程端口共同区分，同一个服务器监听端口可对应许多已建立连接。区分协议时还应考虑 TCP 或 [[计算机/基础/网络/UDP|UDP]]。

## 示例

两名用户都连接同一服务器的 TCP 443，因远端地址或端口不同，服务器能区分两条连接。
