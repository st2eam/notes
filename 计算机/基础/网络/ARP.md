# ARP

## 定义

ARP 在同一 IPv4 链路内，根据下一跳 [[计算机/基础/网络/IP协议|IP]] 地址查询对应 MAC 地址。

## 工作原理

ARP 查询的是当前链路上的下一跳地址。

1. 发送方先确定下一跳 IP 地址。
2. 检查 ARP 缓存中是否已有相应的 MAC 地址。
3. 如果没有，在本地链路广播 ARP 请求。
4. 对应设备通常用单播应答，发送方据此建立映射并发送帧。

跨网络通信时，下一跳通常是路由器。因此，主机查询的是网关的 MAC 地址，而不是远程服务器的 MAC 地址。

ARP 广播不会被普通路由器继续转发到远端网络。
