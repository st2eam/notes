# IPv6 基本首部与扩展首部

## 定义

[[计算机/基础/网络/IPv6|IPv6]] 用固定 40 字节基本首部配合可选扩展首部组织数据报。

## 工作原理

基本首部包含下一首部、跳数限制等字段，不再设置 IPv4 那样的首部检验和。

数据报可按下面的形式组织：

```text
IPv6 基本首部 → 扩展首部（可选） → TCP、UDP 等上层内容
```

“下一首部”字段逐段指出后面内容的类型。有效载荷长度不包含固定的 40 字节基本首部。

中间路由器不对 IPv6 数据报分片。必要的分片由源端完成。
