# IP 地址标识接口

## 定义

IPv4 地址是 32 位逻辑地址，用于标识主机或路由器连接网络的接口。

## 工作原理

一台设备可有多个接口和多个地址，不能把 [[计算机/基础/网络/IP协议|IP]] 地址简单看成整台设备永久唯一的编号。地址是否需全球唯一，要结合公用地址、专用地址和具体作用域判断。

## 示例

路由器面向家庭 LAN 的接口与面向运营商的接口通常拥有不同地址。
