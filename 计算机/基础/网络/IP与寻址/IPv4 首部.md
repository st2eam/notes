# IPv4 首部

## 定义

IPv4 首部携带版本、首部长度、总长度、标识、分片信息、[[计算机/基础/网络/IP与寻址/TTL|TTL]]、上层协议、首部检验和及地址等字段。

## 工作原理

没有选项时，IPv4 首部为 20 字节。解析长度时，要区分字段的单位和计算范围。

| 字段 | 含义 |
| --- | --- |
| 首部长度 | 以 4 字节为单位表示首部大小 |
| 总长度 | 首部与数据的总字节数 |
| 标识、标志、片偏移 | 供分片与重组使用 |
| TTL | 限制数据报能够继续转发的跳数 |
| 协议 | 指明交付给 [[计算机/基础/网络/TCP|TCP]]、[[计算机/基础/网络/UDP|UDP]]、[[计算机/基础/网络/IP与寻址/ICMP|ICMP]] 等哪种上层协议 |
| 首部检验和 | 只检查首部，不覆盖有效载荷 |

源、目的地址分别说明数据报的发送方和最终接收方。

## 示例

总长度为 1500、首部长度为 20 字节的数据报，所承载的上层数据为 1480 字节。
