# 双协议栈与隧道

## 定义

双协议栈让设备同时支持 IPv4 和 [[计算机/基础/网络/IPv6|IPv6]]；隧道把一种网络层分组作为另一种网络层分组的数据传送。

## 工作原理

双栈根据通信双方能力使用相应协议；隧道让 IPv6 等分组穿过不直接支持它的网络。隧道封装不会自动实现地址版本之间的语义转换。

## 示例

两端 IPv6 网络之间只有 IPv4 传输设施，可在隧道入口增加 [[计算机/基础/网络/IP与寻址/IPv4 首部|IPv4 首部]]，出口再去掉它。
