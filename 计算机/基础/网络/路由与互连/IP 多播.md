# IP 多播

## 定义

IP 多播把数据交付给一个接收组，由网络在需要分支的位置复制分组。

## 工作原理

源端不必为每个接收者分别发送完整副本，路由器依据多播转发状态形成分发路径。IPv4 多播地址属于 `224.0.0.0/4`，标识组而不是普通主机接口。

## 示例

同一条上游链路只承载一份直播流，在接近不同接收分支时再复制。
