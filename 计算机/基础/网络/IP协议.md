# IP协议

## 定义

IP 提供无连接的数据报服务，每个数据报独立寻址和转发。

## 工作原理

网络不为每次端到端通信预留专用连接，也不承诺无丢失、无重复、按序到达或有限时延。尽最大努力表示按现有资源转发，不表示可以随意丢弃或无需实现规范。

## 示例

两个相继发送的 IP 数据报可能走不同路径，[[计算机/基础/网络/TCP|TCP]] 再负责按序整理其中的数据。

## 异构网络互连

虚拟互连网络用统一的 IP 地址和数据报格式，覆盖多种底层网络。

每一跳使用适合本地链路的帧，路由器取出 IP 数据报再重新封装。IP 负责尽最大努力转发，不承诺交付、顺序或时限；需要更强服务的端系统继续补足相应机制。
