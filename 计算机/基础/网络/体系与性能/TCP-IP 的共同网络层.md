# TCP/IP 的共同网络层

## 定义

TCP/IP 用 [[计算机/基础/网络/IP协议|IP]] 作为多种应用与多种底层网络之间共同的网络层。

## 工作原理

“各种应用运行在 IP 之上、IP 运行在各种网络之上”使应用扩展和媒体演进可以相对独立。统一的是互连所需的抽象，不是所有网络内部实现。
