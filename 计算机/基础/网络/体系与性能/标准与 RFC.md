# 标准与 RFC

## 定义

RFC 是互联网技术文档系列，IETF 通过开放讨论与技术审查推动协议规范。

## 工作原理

RFC 既包含标准轨道文档，也包含实验性、信息性等文档；“有 RFC 编号”不等于“已成为互联网标准”。互操作依赖双方遵循一致规范。
