# 副作用

副作用是代码求值或执行时，除产生结果之外，对可观察状态造成的影响。例如，修改外部变量、修改调用方传入的对象、写文件、更新页面和发送网络请求。

“副作用”是技术术语，不表示操作有害。保存文件、更新界面等程序功能本身就需要副作用。

## 修改外部状态

```js
let counter = 0;

function nextId() {
    counter += 1;
    return counter;
}

nextId(); // 1
nextId(); // 2
```

`nextId` 既返回新编号，也修改外部变量 `counter`。后一次调用的结果依赖前一次调用留下的状态，因此调用顺序会影响行为。

## 修改传入的对象

```js
function markDone(task) {
    task.done = true;
}

const task = { done: false };
markDone(task);
// task.done 为 true
```

JavaScript 按值传递参数，但对象引用也是值。函数通过这个引用修改对象属性，调用方能够观察到变化，因此产生了副作用。

若只需计算新状态，可以返回新对象：

```js
function withDone(task) {
    return { ...task, done: true };
}
```

## 与外部依赖的区别

读取可变外部变量不一定修改状态，却会让结果依赖函数参数之外的信息。`Date.now()` 也会随时间返回不同结果。因此，“没有修改外部变量”不足以证明一个函数是[[计算机/基础/编程概念/纯函数|纯函数]]。

I/O 涉及外部环境，一般按效应处理。测试这类代码时，需要控制文件、网络或时钟等依赖，或将它们与计算逻辑分开。

React 的 [[计算机/前端/React/Hooks/useEffect|useEffect]] 用于管理组件与外部系统同步时产生的副作用，例如订阅事件或更新浏览器标题。
