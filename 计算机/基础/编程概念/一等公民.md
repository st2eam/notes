# 一等公民

“一等公民”（first-class citizen）也称“一等值”“一等对象”或“第一类对象”，指编程语言中支持全套普通值操作的实体。它描述一个实体能参与哪些操作，不表示重要性或优先级。

## 判定标准

一个实体是一等公民，通常意味着它可以：

1. 赋给变量或绑定名字；
2. 存入数组、列表、字典等数据结构；
3. 作为函数参数传入；
4. 作为函数返回值传出；
5. 在运行时创建，并独立于名字存在。

不同语言和文献列出的条件不完全一致，前四项是最常见的操作集合。“一等”只说明语言允许的操作范围，不是等级。

## 函数作为一等公民

Python 中函数可以直接赋值和传递：

```python
def inc(x):
    return x + 1

f = inc                  # 赋给变量
funcs = [inc, str]       # 存入数据结构

def apply(fn, x):        # 作为参数
    return fn(x)

def make_adder(n):       # 作为返回值
    return lambda x: x + n

assert apply(inc, 1) == 2
assert make_adder(10)(5) == 15
```

[[计算机/编程语言/Python/python函数|Python 函数]]的 `def` 创建的是普通对象，因此可以这样使用。Java 的方法本身不是值；Java 8 的 lambda 和方法引用会创建函数式接口的实例，才能作为参数或返回值传递：

```java
import java.util.function.Function;

Function<Integer, Integer> inc = x -> x + 1;
```

C 通过函数指针传递函数：

```c
int inc(int x) { return x + 1; }

int (*f)(int) = inc;
```

函数指针能完成赋值、传递和返回，但不能创建带捕获环境的匿名函数，函数本身也不是对象；是否算一等公民取决于对“一等”的定义。[[计算机/编程语言/C++/C++Lambda表达式|C++ lambda 表达式]]把代码和捕获的环境打包成函数对象，可以赋值和传递。

## 常见的一等公民

- 数字、字符串、布尔值：多数语言中的基本值。
- 函数：Python、JavaScript、Haskell 等语言中是标准的一等公民；Java 8+ 通过 lambda 和方法引用提供；C 通过函数指针。
- 类与对象：Python、JavaScript 中类本身可以作为值传递。
- 类型：反射或依赖类型语言中，类型可以由值表示，或直接作为值使用。

## 与其他概念的关系

- **高阶函数**：接受或返回函数；通常以函数是一等公民为前提。
- **闭包**：函数值捕获定义时的环境，是一等函数常见的实现方式。
- **一等模块、一等类型**：同一思想扩展到其他语言实体。

## 常见误解

- “一等公民就是更重要的东西。”不是，它只描述可参与的操作。
- “一等公民一定是纯函数。”无关；一等公民同样可以带副作用。
- “Java 的方法是一等公民。”方法本身不是；lambda 或方法引用包装出的函数式接口实例才具备这一性质。
