# 高阶函数

高阶函数是接受函数作为参数，或返回函数的函数。满足其中任意一项即可。

JavaScript 中函数是[[计算机/基础/编程概念/一等公民|一等公民]]，可以像普通值一样赋值和传递，这使高阶函数可以直接表达。

## 接受函数参数

```js
function apply(fn, value) {
    return fn(value);
}

const double = x => x * 2;
apply(double, 3); // 6
```

`apply` 接收函数 `fn`，因此是高阶函数。`double` 接收的是数值，本身不是高阶函数。两者的区别在于参数或返回值中是否包含函数，而不在于使用 `function` 还是箭头函数语法。

数组方法 `map` 也是高阶函数：

```js
const numbers = [1, 2, 3];
const doubled = numbers.map(x => x * 2);
// doubled 为 [2, 4, 6]
```

传给 `map` 的函数是回调函数；接收这个回调的 `map` 是高阶函数。

## 返回函数

```js
function makeAdder(amount) {
    return x => x + amount;
}

const add10 = makeAdder(10);
add10(5); // 15
```

`makeAdder` 返回函数，因此是高阶函数。返回的函数保留了对 `amount` 的访问，这属于[[计算机/编程语言/JavaScript/Function/JS 函数#JavaScript 闭包|闭包]]的用法。

## 与纯函数的关系

高阶函数描述参数和返回值的种类；[[计算机/基础/编程概念/纯函数|纯函数]]描述结果依赖和副作用。两者不是同一个条件。

高阶函数可以执行 I/O，也可以调用带副作用的回调。例如，`map` 的回调若修改外部变量，整个调用就会产生副作用。
