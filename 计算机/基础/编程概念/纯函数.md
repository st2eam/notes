# 纯函数

纯函数的返回结果只取决于输入，相同输入得到相同结果，并且不产生[[计算机/基础/编程概念/副作用|副作用]]。修改调用方传入的对象、写文件、发送网络请求，都不符合纯函数的要求。

```js
function add(x, y) {
    return x + y;
}

add(3, 2); // 5
```

在参数为普通数值时，`add` 的结果只由两个参数决定，可以用[[数学/数学函数|数学函数]]描述其输入与输出的关系。

## 返回值之外的依赖

函数只返回一个值，并不意味着它是纯函数：

```js
let rate = 0.1;

function tax(amount) {
    return amount * rate;
}
```

`tax` 没有修改外部变量，但它读取了可变的 `rate`。改变 `rate` 后，同一个 `amount` 会得到不同结果，因此它不是纯函数。

将税率改为显式参数，可以消除这项隐藏依赖：

```js
function calculateTax(amount, rate) {
    return amount * rate;
}
```

读取不可变常量通常不影响纯性。读取当前时间、随机数或可变外部状态则会使结果受调用时机影响。

## 对象参数与局部修改

纯函数可以创建并修改只在函数内部使用的新对象；关键是修改是否影响调用者可观察的状态。

```js
function append(items, item) {
    const result = [...items];
    result.push(item);
    return result;
}

const original = [1, 2];
const updated = append(original, 3);
// original 仍为 [1, 2]，updated 为 [1, 2, 3]
```

直接执行 `items.push(item)` 会修改传入的数组，产生副作用。这里复制的是数组本身；若随后修改其中嵌套对象的属性，仍可能影响原数据。

## 使用范围

纯函数便于单独测试，也便于推理调用顺序是否影响结果。程序中的 I/O 通常仍然需要执行，可以由外层代码读取数据、调用纯函数计算，再写出结果。

纯性不保证所有输入都能正常返回，也不保证浮点计算精确。判断程序是否完整实现某个数学函数，还需要检查输入范围、终止性和数值误差。
