# 程序函数与数学函数

数学函数是集合之间的映射规格，程序函数是这段映射的可执行实现。两者外形相同：有名字、接收参数、给出结果。但数学函数只描述输入与输出的对应关系，程序函数还包含计算过程、状态和运行环境。JavaScript 中函数是一等公民；对象方法还带隐式接收者 `this`，下面先忽略这一层。

## 形式上的对应

| 数学 | 程序（JavaScript） |
|---|---|
| 函数名 `f` | 函数名 `f` |
| 参数表 `(x, x1)` | 形参表 `(x, x1)` |
| 定义域 `X×Y` | 无类型约束，调用时传入 |
| 对应法则 `x + x1*100` | 函数体 `return x + x1 * 100;` |
| 陪域 / 值域 `Z` | 返回值（此例为 `Number`） |

数学里的定义：

$$
f(x, x_1) = x + x_1 \times 100.
$$

对应的程序实现：

```js
function f(x, x1) {
    return x + x1 * 100;
}
```

数学函数的形式定义是：设 X、Y 为集合，函数 $f: X \to Y$ 对每个 $x \in X$ 指定唯一的 $y \in Y$。X 是定义域，Y 是陪域，$f(X)$ 是值域。数学里的 $f(x, x_1) = \dots$ 是在声明一个具名映射；JavaScript 函数给出它的可执行版本。`f(x)` 没有神秘之处，它就是给一段映射规则起名，然后复用调用。

## 共同本质：输入到输出的确定性映射

两者的共同点是：给定一组输入，按确定的规则得到一个输出。

- 数学函数要求单值性：同一个输入不能对应多个输出。
- 纯函数要求相同输入总得到相同输出，不修改外部状态，不做 I/O，也不依赖可变的外部状态。

因此，纯函数是数学函数在程序中的直接实现形式。上例中 $f(3, 2) = 3 + 2 \times 100 = 203$，数学与程序的结果一致。

## 关键差别

| 维度 | 数学函数 | 程序函数 |
|---|---|---|
| 性质 | 输入与输出的对应关系（外延） | 对应关系 + 计算过程（内涵） |
| 副作用 | 没有执行过程，无所谓副作用 | 可读写外部状态、做 I/O、用随机数、抛异常 |
| 定义域 | 可无限，如整数、实数 | 受数值表示限制，如 JS `Number` 的安全整数上限为 $2^{53}-1$ |
| 相等 | 对所有输入输出相同即相等 | 一般只能比较引用；语义等价不可判定 |
| 失败 | 定义域外无定义 | 可能抛异常、返回 `null` 或永不终止 |
| 角色 | 映射本身是值 | 可作为值传递（高阶函数） |

### 外延与内涵

数学只看输入与输出的对应关系；程序还看算法、效率和内存。同一个数学函数可以有多种写法，数学上它们相等，代码里却是不同实现。

### 副作用

程序函数可能修改全局变量、写文件、发网络请求或读取时间；调用一次，外部世界可能改变。数学函数没有“执行一次世界就变了”的概念。

### 数值表示只是定义域的近似

JavaScript 不检查参数类型，但 `Number` 是 IEEE 754 双精度浮点，安全整数范围是 $\pm(2^{53}-1)$。超出这个范围后，整数运算可能丢失精度；需要精确的大整数时使用 `BigInt`。因此，输入足够大时，JS 版也不再是数学意义上的那个函数。

### 相等不可判定

数学上 $f = g$ 只需对所有输入的结果相同；程序里判定两个函数对所有输入等价，在通用编程语言中不可判定（Rice 定理），所以通常只能比较引用。

### 部分性与失败

数学的 $1/x$ 在 0 处无定义，是部分函数；程序里对应除零异常、`null` 或不终止（bottom）。纯函数也可能不终止，因此它对应的仍是部分函数，不一定是全函数。

### 函数可以是一等公民

函数可以像普通值一样赋给变量、存入数据结构、作为参数传入或作为返回值传出。这种性质称为[[计算机/基础/编程概念/一等公民|一等公民]]（first-class citizen），也常写作一等值或一等对象。

数学上函数同样可以作为整体参与等式、求导和复合；程序中的高阶函数对应数学中的算子或泛函，例如导数算子 $D(f) = f'$。

## 更深的结构对应

- **复合**：$h(x) = f(g(x))$ 对应 `f(g(x))` 的嵌套调用。
- **递归**：$n! = n \cdot (n-1)!$ 对应递归函数；数学归纳法对应结构递归。
- **多参数与柯里化**：$f(x, y)$ 与 $f(x)(y)$ 对应，后者接近 λ 演算的原始形式。
- **恒等函数与常函数**：$\mathrm{id}(x) = x$、$c(x) = k$ 对应程序中的 identity 与常量函数。
- **理论基础**：程序语言的函数概念来自 λ 演算与集合论；函数式编程把数学函数做成可计算的语法对象。

## 一句话总结

数学函数是规格说明（what：输入与输出的对应关系），程序函数是实现（how：算出来的过程）。当程序函数是纯函数、能够终止且无副作用时，二者重合。
