# 程序函数与数学函数

[[数学/数学函数|数学函数]]描述输入与输出的对应关系；程序函数是一段可调用的代码。程序函数可以实现数学函数，也可以执行读写文件、修改状态等操作。

## 输入、规则与输出

以一个接收两个数的函数为例：

$$
f(x, y) = x + y \times 100.
$$

对应的[[计算机/编程语言/JavaScript/Function/JS 函数|JavaScript 函数]]实现：

```js
function f(x, y) {
    return x + y * 100;
}

f(3, 2); // 203
```

两者使用相同的计算规则：先将第二个输入乘以 100，再加上第一个输入。给定输入 3 和 2，结果都是 203。

| 数学 | JavaScript |
|---|---|
| 函数名 $f$ | 函数名 `f` |
| 自变量 $x$、$y$ | 形参 `x`、`y` |
| 代入 $f(3, 2)$ | 调用 `f(3, 2)` |
| 对应法则 $x + y \times 100$ | 函数体中的 `x + y * 100` |
| 函数值 203 | `return` 返回的数值 203 |

数学函数的定义还包括定义域和陪域。记作 $f: A \to B$，表示对每个 $a \in A$，都有唯一的 $f(a) \in B$。A 是定义域，B 是陪域，所有实际输出组成的集合 $f(A)$ 是值域。函数的输入和输出也可以是字符串、集合等对象，不限于数。

JavaScript 的形参不声明类型。要让上面的代码按预期完成数值运算，需要约定两个参数都是数值。例如，传入字符串时，`f("3", 2)` 得到的是字符串 `"3200"`，因为 `+` 会进行字符串拼接。

## 纯函数与副作用

[[计算机/基础/编程概念/纯函数|纯函数]]的结果只取决于输入，相同输入得到相同结果，也不产生[[计算机/基础/编程概念/副作用|副作用]]，例如修改外部状态或执行 I/O。上面的 `f` 在参数为普通数值时满足这些条件，可以用数学函数描述其输入与输出的关系。

程序函数也可以依赖和修改外部状态：

```js
let counter = 0;

function nextId() {
    counter += 1;
    return counter;
}

nextId(); // 1
nextId(); // 2
```

`nextId()` 没有显式参数，两次调用却返回不同结果，因为它读取并修改了外部变量 `counter`。因此，仅按显式参数，无法把它描述为固定的输入到输出的映射。若将计数器状态也纳入输入和输出，就可以用数学函数描述这次状态变化。

## 数值表示与执行限制

数学中的整数没有大小上限。JavaScript 的 `Number` 使用 IEEE 754 双精度[[计算机/基础/编程概念/浮点数|浮点数]]表示，安全整数范围为 $-(2^{53}-1)$ 到 $2^{53}-1$；超出范围后，不能保证每个整数都能被精确表示。小数运算也可能产生舍入误差，例如 `0.1 + 0.2 !== 0.3`。因此，代码与数学表达式写法相同，不保证在所有输入下结果都精确一致。

数学函数在定义域内每个输入上都有值。例如，实数函数 $h(x) = 1/x$ 可以将定义域设为 $\mathbb{R} \setminus \{0\}$。程序则可能抛出异常或不终止；即使没有副作用，也仍需检查它是否能在约定的输入范围内正常返回。具体行为取决于语言和运算：JavaScript 中 `1 / 0` 返回 `Infinity`，不会抛出除零异常。

同一个数学函数可以有不同的程序实现。例如，求和可以逐项累加，也可以使用求和公式。两种实现可能得到相同结果，但时间、内存开销不同。JavaScript 的 `===` 比较两个函数时，判断的是它们是否为同一个函数对象，不会比较计算规则是否相同。

## 函数作为参数和返回值

JavaScript 中，函数可以赋给变量、存入数组、作为参数或返回值。这种性质称为[[计算机/基础/编程概念/一等公民|一等公民]]。接受函数或返回函数的函数称为[[计算机/基础/编程概念/高阶函数|高阶函数]]。

数学中也可以把函数作为运算对象。例如，[[数学/函数复合|函数复合]] $h(x) = f(g(x))$ 对应以下写法：

```js
const inc = x => x + 1;
const double = x => x * 2;
const h = x => inc(double(x));

h(3); // 7
```

这里 `h` 先计算 `double(x)`，再把结果交给 `inc`，与数学中的复合顺序一致。
