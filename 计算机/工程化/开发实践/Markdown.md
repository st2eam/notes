# Markdown

Markdown 是一种便于直接阅读和编写的纯文本标记语法，也指其最初的文本转 HTML 工具。标题、列表、引用、链接和代码块等标记用于表达文档的基本结构。

在 AI 知识管理中，Markdown 便于提取文字、检查逐行修改和迁移正文。它通常不保存原文档的字体、坐标和分页；需要精确版式时仍应保留原件。双链、插件组件和扩展语法的兼容性也需要单独检查。
