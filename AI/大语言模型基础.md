# 大语言模型基础

> 前置：[机器学习数学基础](./机器学习数学基础.md)中的向量和注意力部分。目标：解释 token、上下文、训练与推理，以及模型为什么需要外部证据。最后核对：2026-09-29。

大语言模型学习序列中的规律，并在给定上下文后预测后续 token。生成能力并不等于拥有可靠、实时或获授权的事实来源。做应用时，模型输出应被视为需要验证的候选结果。

## 核心概念

| 概念 | 用途 | 容易误解之处 |
|------|------|-------------|
| Token | 模型处理文本的单位，影响上下文和计费 | 一个字或一个词不固定等于一个 token |
| 上下文窗口 | 一次请求能使用的输入与输出容量 | 放进窗口不保证每条信息都被正确利用 |
| Temperature | 调整采样分布 | 设为 0 也不保证跨环境逐字一致 |
| 推理 | 用既有参数生成结果 | 不会自动更新模型参数 |
| 训练/微调 | 通过数据与优化改变参数 | 不是给一次提问附加新资料 |

不同模型对参数的支持和含义可能不同，使用前核对所选接口文档。把“模型能记住多少”与“应用可检索多少资料”分开考虑。

## Transformer 的一条主线

文本先被切成 token，再映射为向量。注意力计算让当前位置对上下文中不同位置分配权重；前馈层等模块继续变换表示。训练时通过损失函数和梯度更新参数；推理时根据当前上下文反复生成下一步。

注意力的核心形式是：

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

Q 表示当前查询，K 用来匹配，V 是被加权汇总的信息。想亲手观察权重变化，可操作[注意力实验台](./机器学习数学基础.md#缩放点积注意力)。

## 模型、证据与行动

- **Prompt** 描述任务、约束和已有上下文；清晰指令提高可控性，但不能替代事实核验。
- **检索**把外部资料带进上下文，降低知识过时的问题；检索错误仍会传播到回答。
- **工具**让模型建议查询或操作。实际调用由应用执行，并需通过授权与参数校验。
- **评测**用固定任务集检查质量，而不是凭个别流畅回答判断。

~~~python
evidence = search_allowed_documents(user, question)
response = model.generate(
    question=question,
    evidence=evidence,
    instruction="仅引用提供的证据；证据不足时明确说明",
)
return validate_sources(response, evidence)
~~~
