## 向量与相似度

向量是有顺序的数值列表。点积把对应位置相乘后求和；余弦相似度再除以两个向量的长度，描述方向的接近程度。接近不意味着事实正确，分数也依赖具体模型。

~~~python
from math import sqrt

def dot(a, b):
    assert len(a) == len(b)
    return sum(x * y for x, y in zip(a, b))

def cosine(a, b):
    length = sqrt(dot(a, a) * dot(b, b))
    return dot(a, b) / length if length else 0.0

assert dot([1, 2], [3, 4]) == 11
assert cosine([1, 0], [0, 1]) == 0.0
~~~

## 导数、梯度与自动微分

导数描述输入微小变化时输出如何变化。对损失函数的每个参数求偏导，组成梯度；梯度下降沿负梯度方向更新参数。自动微分通过记录运算关系计算这些导数，PyTorch 的 autograd 用于此过程。

例如损失 L(w) = (w − 3)²，其导数是 2(w − 3)。w = 0 时导数为 −6；用学习率 0.1 更新得到 w = 0.6，离最优值 3 更近。学习率过大可能越过最优点，过小则收敛缓慢。

## 缩放点积注意力

Query 与每个 Key 点积，除以维度平方根，再经 softmax 转为总和为 1 的权重。模型用权重对对应的 Value 加权求和。下面实验台只展示其中的打分和归一化步骤。

<AttentionLab />

下面的**可运行 Python 3 示例**对应实验台的“偏技术”查询：

~~~python
from math import exp, sqrt

query = [1, 0]
keys = [[1, 0], [0, 1], [1, 1]]
scores = [sum(a * b for a, b in zip(query, key)) / sqrt(2) for key in keys]
scale = max(scores)
values = [exp(score - scale) for score in scores]
weights = [value / sum(values) for value in values]
assert abs(sum(weights) - 1) < 1e-12
print([round(weight, 3) for weight in weights])
~~~
