# AI 学习路线：从 Web 开发到可靠应用

> 面向会写 JavaScript、能理解 HTTP 请求的读者。最后核对：2026-09-29。

这条路线的目标是：看懂模型能做什么，接入数据与工具，独立判断回答是否可靠。先完成一条可运行的应用路线，再按兴趣深入模型原理。每篇教程中的“教学模拟”和“模型接口伪代码”都有明确标注；浏览器实验台不会调用外部模型。

## 路线 B：理解模型原理

先读[机器学习数学基础](./机器学习数学基础.md)，再读[大语言模型基础](./大语言模型基础.md)、[LLM 演进路线](./LLM演进路线.md)和已有的[PyTorch 入门](../Python/NLP/PyTorch/快速入门.md)。这一线侧重向量、梯度、注意力及训练流程；训练大模型还需要更系统的数学、数据和计算资源知识。

## 如何使用这套笔记

1. 先了解每篇的学习目标，再阅读讲解、运行示例并操作实验台。
2. 运行标为“可运行”的 Python 代码；标为“伪代码”的模型接口只用于说明数据流。
3. 在实战中记录失败样本、来源和修改后的结果。能解释失败原因，比背下框架名称更重要。

模型 API 和产品名称变化快，教程尽量讲稳定的数据流与评测方法。学习时以每篇末尾的官方资料为准，并核对最新版本。
