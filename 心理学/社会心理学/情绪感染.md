# 情绪感染

**情绪感染**指一个人的情绪表达影响他人的情绪，使互动者的情绪可能趋同。表情、语调和行动节奏可以提供线索。在会议中，一位成员显得紧张，其余人随之紧张，可能是他们在响应这个人的情绪，也可能是同时得知了同一个坏消息。区分这两种解释，需要了解谁先接触哪一项信息，以及情绪随交流次序怎样变化。

Barsade 在实验小组中让一位受过训练的参与者表现不同情绪，观察其他成员的情绪和小组互动。研究发现情绪可以在小组内传播，并与合作、冲突等过程有关。实验操纵的是成员表达的情绪，适用范围由研究情境决定。[Barsade（2002）](https://doi.org/10.2307/3094912)

勒庞在[[心理学/社会心理学/心理群体]]中把情绪、信念和行动的扩散合称为「传染」。现代讨论可以分开问：人们是感到同样的紧张、相信了同一种解释，还是跟随了同一种行动？这三个变化需要各自的证据。为获得认可而改变公开行为的情况，可以参看[[心理学/社会心理学/从众]]。
