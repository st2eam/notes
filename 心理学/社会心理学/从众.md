# 从众

**从众**指个人因实际或感知到的群体影响，使判断或行为向群体中的其他人靠拢。多人做出相同选择也可能出于相同的独立信息。要辨认从众，需要比较个人在知道和不知道群体反应时如何选择。

Deutsch 与 Gerard 区分两种社会影响。**信息性影响**发生在人把别人的回答当作判断事实的线索时。**规范性影响**发生在人为了符合群体期待、获得认可或避免疏远而改变公开表现时。两者可以同时发生。在陌生的会议里跟着举手，有人以为其他成员掌握更多资料，也有人只是不愿公开反对。[Deutsch 与 Gerard（1955）](https://doi.org/10.1037/h0046408)

## 判断发生了什么变化

分开记录独立判断、看到多数意见后的公开表态，以及之后在私下仍相信什么。公开附和可以在私下信念不变时出现。讨论后多数成员沿原有倾向走得更远，涉及[[心理学/社会心理学/群体极化]]。勒庞在[[心理学/社会心理学/心理群体]]中把多种趋同都归入暗示与传染，现代研究提供了更具体的比较条件。
