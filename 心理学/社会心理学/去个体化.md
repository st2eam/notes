# 去个体化

**去个体化**（deindividuation）是解释人在匿名、难以被单独辨认或沉浸于集体活动时，自我注意与行为约束可能如何变化的一类理论。早期解释强调个人责任感和自我约束减弱。勒庞关于[[心理学/社会心理学/心理群体]]的讨论有相近的设问，但它还诉诸本能、暗示和当时的种族观，理论背景不同。

## 群体规范与行为方向

Postmes 与 Spears 汇总既有实验，发现群体情境中的行为更适合结合当下规范解释。个人身份线索减少时，人仍可能以共同身份为参照。如果社群鼓励互助，匿名成员也可能热心答疑。如果社群赞许羞辱他人，成员可能顺从这种规范。[[心理学/社会心理学/社会认同]]解释了为什么人会把特定群体的规则当作自己的行动参照。[Postmes 与 Spears（1998）](https://doi.org/10.1037/0033-2909.123.3.238)

分析实际事件时，可以分开看个人是否真能匿名、谁能追究行为、群体奖惩什么，以及成员是否将自己看作该群体的一员。匿名是一种情境条件，侵害或互助则是需要解释的结果。
