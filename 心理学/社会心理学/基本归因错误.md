# 基本归因错误

**基本归因错误（fundamental attribution error）**指解释他人的行为时，倾向于高估性格、能力、态度等个人因素的影响，低估环境、角色、规则和压力等情境因素的影响。[来源：APA 定义](https://dictionary.apa.org/fundamental-attribution-error)

例如，同事开会迟到，观察者立即判断“这个人时间观念差，不尊重大家”，却没有充分考虑交通中断、临时紧急任务或会议通知错误等可能性。迟到是观察到的行为，“不尊重大家”则是对行为原因和个人态度的推断。

## 内部归因与外部归因

归因是对行为或事件原因的解释。

| 归因方式 | 解释重点 | 示例 |
| --- | --- | --- |
| 内部归因 | 性格、能力、动机、态度等个人因素 | 没按时交付任务，是因为缺乏责任心 |
| 外部归因 | 资源、规则、任务难度、偶发事件等情境因素 | 没按时交付任务，是因为需求反复变化、时间不足 |

个人因素与情境因素可以共同作用。基本归因错误的关键是两者的解释权重失衡：证据不足时，过早把行为当成稳定个人特征的表现。

## 形成机制

- **注意的显著性**：观察别人时，行动者通常比背景条件更显眼，容易成为解释的中心。
- **信息不对称**：观察者能看到行为结果，却未必知道对方掌握的信息、可选方案和受到的限制。
- **判断与修正的认知成本**：人可能先形成对个人特征的判断，再根据情境修正；时间压力、分心或认知负荷可能使修正不足。

这些是理解归因偏差的常见解释，不能据此断言每一次判断偏差都由同一种机制造成。

## 经典研究：被指定的立场

Jones 与 Harris 在 1967 年的研究中，让参与者阅读支持或反对卡斯特罗的文章，并推测作者本人的态度。在部分条件下，参与者知道作者的写作立场由实验者指定，仍倾向于从文章立场推断作者本人的态度。

这个结果说明：即使情境约束已经明确，人们仍可能没有充分降低行为对个人态度判断的影响。该研究常用于说明基本归因错误及与之密切相关的对应偏差。[来源：Jones 与 Harris，1967](https://doi.org/10.1016/0022-1031(67)90034-0)

## 与相近概念的区别

| 概念 | 核心含义 |
| --- | --- |
| 基本归因错误 | 解释他人行为时，高估个人因素、低估情境因素 |
| 对应偏差 | 从行为推断与之对应的稳定特征，即使该行为可以由情境充分解释；与基本归因错误高度重叠，文献中有时混用 |
| [[心理学/社会心理学/行动者—观察者差异|行动者—观察者差异]] | 经典假说认为，对自己的行为更倾向于情境解释，对他人的行为更倾向于个人解释；其出现受条件影响，并非普遍规律 |
| [[心理学/社会心理学/自利性偏差|自利性归因偏差]] | 把成功更多归于自身，把失败更多归于外部条件，以维持有利的自我评价 |

“别人迟到是懒散，我迟到是堵车”同时涉及对他人的归因和自他解释的差异。基本归因错误本身不要求存在对自己行为的比较，也不限于负面评价；忽略岗位资源，把一次出色表现全部归于个人能力，同样可能涉及这一偏差。

## 减少归因偏差

1. **区分行为事实与特征判断**：“两次没有按时交付”是行为记录，“没有责任心”是需要进一步证据支持的推断。
2. **补充情境信息**：检查任务要求、资源、权限、激励、时间限制及突发事件。
3. **比较不同条件下的表现**：观察这个人是否在不同时间、不同环境中反复出现相同行为，以及其他人在相同情境下是否也如此。
4. **保留多种解释**：在信息不足时，把个人因素与情境因素视为待检验的假设，避免立即确定唯一原因。

检查自己如何从行为跳到评价，涉及对自身判断过程的觉察与调节，属于[[心理学/认知心理学/元认知|元认知]]的应用。

## 适用边界

基本归因错误是一种判断倾向，不意味着所有内部归因都是错误的，也不意味着情境能够免除个人责任。行为成因、实际后果与责任认定需要分别分析。

这种倾向的强弱受文化背景、情境信息、任务条件和认知资源等因素影响。“基本”不表示它在所有人、所有文化和所有场景中都同样显著。
