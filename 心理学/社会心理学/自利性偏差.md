# 自利性偏差

**自利性偏差（self-serving bias）**也称自利性归因偏差，指解释自己的表现时，倾向于把成功归于能力、努力、判断等内部因素，把失败归于运气、任务难度、资源限制等外部因素，使解释更有利于维持积极的自我评价。[来源：APA 定义](https://dictionary.apa.org/self-serving-bias)

例如，考试成绩好时认为“我能力强、复习方法有效”，成绩差时则强调“题目太偏、考场环境不好”。这种偏差不一定涉及有意识的欺骗，当事人可能确实相信自己的解释。

## 成功与失败的归因不对称

| 结果 | 常见归因 | 对自我评价的作用 |
| --- | --- | --- |
| 成功 | 能力强、努力充分、决策准确 | 强化对自身能力与贡献的肯定 |
| 失败 | 运气差、条件不足、他人配合不佳 | 减轻对自身能力与责任的负面评价 |

偏差的关键是归因标准随结果发生有利于自己的变化。成功可能确实来自个人能力，失败也可能确实受到外部限制；只有结合证据，才能判断解释是否失衡。

例如，在任务难度和资源条件接近的情况下，一个人把成功全部归于自己的判断，把失败全部归于环境，却不检查两种结果中的个人决策与外部条件，就可能表现出自利性偏差。

## 形成机制

- **维护自尊**：承认能力不足或判断失误可能带来挫败感，强调外部限制有助于减轻这种威胁。
- **预期与信息加工**：人通常期待自己的行动取得好结果，成功时容易把结果视为能力的体现，失败时则更容易寻找意外因素。归因差异可能包含对信息的选择性关注。
- **形象管理**：向他人解释结果时，突出贡献、弱化责任可能有助于维护社会评价；这种公开表达不一定与私下判断完全一致。

这些机制可以共同作用。不能仅凭一句有利于自己的解释，就认定当事人在故意推卸责任。

## 典型情境

- **学习评价**：高分归于能力与努力，低分主要归于题目、评分或教学问题。
- **工作复盘**：项目成功时突出个人决策，项目失败时忽略自身决策失误，集中强调市场、资源或协作问题。
- **团队贡献判断**：更容易注意和记住自己的投入，低估他人的贡献。这可能同时涉及信息不对称与记忆偏向，不能把所有贡献分歧都解释为自利动机。

这种偏差可能使复盘遗漏可改进的行为，也可能加剧团队成员对功劳与责任的分歧。

## 与相近概念的区别

| 概念 | 关注的偏向 |
| --- | --- |
| 自利性偏差 | 对自身成功与失败采用更有利于自我评价的归因方式 |
| [[心理学/社会心理学/基本归因错误|基本归因错误]] | 解释他人行为时，高估个人因素、低估情境因素 |
| [[心理学/社会心理学/行动者—观察者差异|行动者—观察者差异]] | 经典假说认为，对自身行为更倾向于情境解释，对他人行为更倾向于个人解释；不以成功或失败的区分为核心，且并非普遍规律 |
| 自我中心偏差 | 判断时过度依赖自己的视角、经验或已知信息，不一定涉及维护积极形象 |

“别人迟到是懒散，我迟到是堵车”主要体现自他归因标准的差异；“我做成了是能力强，没做成是条件差”更直接体现自利性归因。

## 减少归因偏差

1. **事前记录判断**：保留目标、预期、已知限制与决策理由，便于事后检查解释是否随结果改变。
2. **同时检查个人与情境因素**：成功时记录资源、协作与运气，失败时也检查准备、执行和决策。
3. **保持评价标准一致**：比较自己与他人、成功与失败时，使用相同的证据要求。
4. **引入独立反馈**：结合过程记录与其他参与者的观察，补充个人视角中缺失的信息。

对自身判断过程的监控属于[[心理学/认知心理学/元认知|元认知]]的应用。上述方法有助于检查归因依据，不能保证完全消除偏差。

## 适用边界

自利性偏差是一种倾向，其强弱受文化、情绪、任务重要性和社会情境影响，并非每个人在每次成败中都呈现相同模式。

积极的自我评价不等于自利性偏差；承认外部限制也不等于逃避责任。判断应依据解释与证据是否相符，避免只凭一次表态给个人贴标签。
