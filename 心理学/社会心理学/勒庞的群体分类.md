# 勒庞的群体分类

勒庞认为，成员的构成和他们联结的方式会改变[[心理学/社会心理学/心理群体]]的行为。书中区分两类。

| 类别 | 细分 | 联结依据或举例 |
| --- | --- | --- |
| 异质性群体 | 无名称 | 为当下情境聚在一起的街头人群 |
| 异质性群体 | 有名称 | 陪审团、议会等有明确名称和任务的组织 |
| 同质性群体 | 派别 | 共同信仰，可以横跨职业与阶层 |
| 同质性群体 | 身份团体 | 职业、教养或社会地位相近，如军队与僧侣团体 |
| 同质性群体 | 阶级 | 利益、生活习惯和教育等条件相近 |

## 分类能回答什么问题

对于成员背景各异的群体，勒庞尤其看重是否具名。他认为明确的组织身份会带来较强的责任感。讨论[[心理学/社会心理学/陪审团中的判断与证词]]时，还要追问成员对谁负责、以何种程序发言和投票。仅有名称这一点无法透露规则是否有效。

作者还用第一国际的跨国分歧说明共同目标未必消除原有差异。他进而以遗传和固定的民族性格解释这些差异，那是全书的时代性假设。现代[[心理学/社会心理学/社会认同]]研究可以单独考察：在同一次行动中，成员更重视职业、政治主张、共同任务，还是另一种归属。
