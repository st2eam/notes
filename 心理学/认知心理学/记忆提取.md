# 记忆提取

**记忆提取**指访问先前存储的信息的过程。知道某个词的含义，却一时说不出词语，说明存有相关知识与此刻能顺利提取完整答案并不是同一件事。

研究舌尖状态时，研究者区分暂时提取失败与“感觉自己知道”的体验；后者可能受部分信息、相关信息和线索熟悉感影响。[来源：Schwartz 与 Metcalfe，2011](https://pubmed.ncbi.nlm.nih.gov/21264637/)

暂时想不起来不足以证明信息已被彻底遗忘；反过来，强烈的熟悉感也不能保证能提取到正确答案。这个区别有助于理解回忆、认出答案与相信自己记得之间的差异。
