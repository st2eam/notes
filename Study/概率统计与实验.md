# 概率统计与实验：为 AI 评测打基础

> 前置：Python 基础。目标：区分样本与总体，计算常见指标，避免把一次小样本波动误判为改进。最后核对：2026-09-29。

模型每次生成的内容可能不同。比较两套提示词或检索方案时，应先定义任务、样本和评分规则，再看数字。只看几个成功案例无法判断整体质量。

## 从样本到结论

总体是产品可能遇到的所有任务；测试集只是抽取的一部分。抽样要覆盖常见任务、边界情况和容易失败的输入。训练或调参时反复查看的样本，不能再当作独立的最终验收集，这属于数据泄漏。

对于二分类，真正例 TP、假正例 FP、假负例 FN 构成：

- 精确率 = TP / (TP + FP)：预测为正的结果有多少是真的。
- 召回率 = TP / (TP + FN)：真实的正例找回了多少。
- 分母为零时应显式约定指标如何显示，不能让程序悄悄产生无意义的值。

下面是**可运行的 Python 3 示例**：

~~~python
from statistics import mean

old_scores = [1, 1, 0, 1, 0, 1, 0, 1]
new_scores = [1, 1, 1, 1, 0, 1, 0, 1]
print(f"旧方案: {mean(old_scores):.3f}, 新方案: {mean(new_scores):.3f}")
assert mean(new_scores) - mean(old_scores) == 0.125
~~~

这八个样本只说明当前集合上多答对一道，不能证明所有用户问题都提升了。还要查看这道题为何改变、有无其他题变差，并在独立样本上复测。比较成本、延迟和安全性时也要使用同一批任务与相同评分标准。

## 如何设计小实验

1. 写明假设，例如“混合检索比纯向量检索更容易找回专有名词”。
2. 固定 30–50 个有代表性的问题、期望来源和失败类型。
3. 每次只改一个主要变量；记录版本、结果、用时和费用。
4. 分析错例，再在未参与调参的样本上复验。
