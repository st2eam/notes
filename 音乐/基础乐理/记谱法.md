# 记谱法

## 五线谱、线与间

**定义**：五线谱用五条平行线和线间位置标记音高；线与间均由下向上计数。

- 相邻的线、间表示相邻字母音名，是否升降由调号和临时记号决定。
- 超出五条线时添加短线，称加线；加线上下的间也可以放音符。
- **示例**：高音谱表从下往上的五条线为 E4、G4、B4、D5、F5；四个间为 F4、A4、C5、E5。

![高音谱表的线音、间音和中央 C4 的下加一线位置。](/music/diagrams/staff-notes.svg)

## 谱号

**定义**：谱号为五线谱建立音高参照，决定某条线上对应的音。

| 谱号 | 参照位置 | 中央 C4 的位置 |
| --- | --- | --- |
| 高音谱号（G 谱号） | 第二线为 G4 | 下加一线 |
| 低音谱号（F 谱号） | 第四线为 F3 | 上加一线 |
| 中音谱号（C 谱号的一种位置） | 第三线为 C4 | 第三线 |

- **示例**：同一个视觉线位在高音谱号、低音谱号下并不一定表示同一音高。

参考：[谱表、谱号与加线](https://www.musictheory.net/lessons/10)。

## 音符结构与读谱顺序

**定义**：音符由符头及可能出现的符干、符尾或连桁组成；垂直位置主要表示音高，形状与符尾主要表示时值。

- 空心符头无符干：全音符；空心符头有符干：二分音符；实心符头有符干：四分音符。
- 四分音符增加一条符尾成为八分音符，增加两条成为十六分音符；连桁可替代符尾。
- 符干朝上或朝下本身不改变音高；多个声部可用符干方向区分。
- **示例／读谱顺序**：先看谱号、调号、拍号、速度，再逐小节读音高、时值、休止与演奏记号。

时值计算见[[音乐/基础乐理/节奏与节拍|节奏与节拍]]；升降规则见[[音乐/基础乐理/调式与调号|调式与调号]]。

## 简谱

**定义**：简谱用数字 1–7 表示调内音级，以调号说明数字与实际音高的对应。

- `1=C` 时，1–7 在常见大调语境中对应 C、D、E、F、G、A、B；`1=G` 时对应 G、A、B、C、D、E、F♯。
- 数字上方的点表示升高八度，下方的点表示降低八度；`0` 表示休止。
- 数字下方的一条减时线把基本时值减半，两条减为四分之一；数字后的增时线通常增加一个基本时值。
- 简谱后的附点增加该音时值的一半；不能把上方／下方的八度点误读为附点。
- `1=C` 本身不充分指定绝对八度，需结合谱面约定、音域或音频；本组例子需要绝对音高时另写 C4。
- **示例**：规定基本数字为四分音符、1 对应 C4，则 `1 2 3 0` 表示 C4、D4、E4、四分休止，共四拍。

## 常用力度、表情与反复记号

| 记号 | 定义与关键点 | 示例 |
| --- | --- | --- |
| p／f | 弱／强，是相对力度 | 同一旋律用 p 或 f 演奏 |
| mp／mf | 中弱／中强 | mf 不代表某个固定分贝值 |
| cresc.／dim. | 渐强／渐弱 | 四拍长音逐渐增强或减弱 |
| staccato | 断奏；音符上／下方的点 | 缩短实际发声，保留节奏位置 |
| fermata | 延长记号 | 该音或休止延长，长度结合处理 |
| 反复小节线 | 返回指定反复起点 | 起点缺省时通常回到曲首 |
| 第一、第二结尾 | 不同遍数走不同结尾 | 第一遍走第一结尾，反复后走第二结尾 |
| D.C.／D.S. | 回曲首／回 Segno 标记 | 按谱面 al Fine 或 al Coda 继续 |
| Fine／Coda | 指定结束点／尾声 | 依跳转说明结束或进入尾声 |

- 音符旁的**附点**改变时值，音符上／下方的**断奏点**改变奏法，位置不同。
- **原创反复示例**：两小节 A、B 被反复小节线包围，实际顺序为 A–B–A–B。

## 乐器专用谱

**定义**：专用谱把音符转换为乐器的操作位置，但不一定完整提供节奏和表情。

- 口琴常标孔号、吹吸与按键，各教材符号不同，先看图例。
- 尤克里里四线谱（TAB）标弦与品位；没有时值标记时，应与五线谱或节奏说明合看。
- **示例**：口琴“1 孔松键吹”为 C4；尤克里里一弦三品为 C5。两者音名同为 C，但相差一个八度。

参见[[音乐/半音阶口琴/构造与音位|孔号记法]]、[[音乐/尤克里里/和弦与指板|四线谱]]。
