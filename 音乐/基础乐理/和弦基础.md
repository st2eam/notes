# 和弦基础

## 和弦与和弦音

**定义**：和弦是按一定音程关系组织的多个音的结合。常见三和弦由根音、三音、五音构成。

- 根音用于确定和弦名称；三音和五音分别指根音上方三度与五度的和弦成员。
- “三个音”指三个不同的和弦音类别，可以重复或放在不同八度。
- **示例**：C 大三和弦包含 C、E、G；四弦尤克里里弹出的 G4–C4–E4–C5 仍属于 C 和弦。

## 三和弦

| 类型 | 相对根音的半音数 | 常见符号 | C 为根音的示例 |
| --- | --- | --- | --- |
| 大三和弦 | 0、4、7 | C、Cmaj | C–E–G |
| 小三和弦 | 0、3、7 | Cm、Cmin | C–E♭–G |
| 减三和弦 | 0、3、6 | Cdim、C° | C–E♭–G♭ |
| 增三和弦 | 0、4、8 | Caug、C+ | C–E–G♯ |

- 大、小和弦的三音不同；不能仅凭音量或个人情绪判断和弦性质。
- **示例**：A–C–E 为 Am；A–C♯–E 为 A。

参考：[三和弦](https://www.musictheory.net/lessons/40)。

## 七和弦与常用符号

**定义**：七和弦在三和弦基础上增加根音上方七度的音。

| 符号 | 结构 | 示例 |
| --- | --- | --- |
| Cmaj7 | 大三和弦＋大七度 | C–E–G–B |
| C7 | 大三和弦＋小七度，属七结构 | C–E–G–B♭ |
| Cm7 | 小三和弦＋小七度 | C–E♭–G–B♭ |
| Csus4 | 以四度音替代三音 | C–F–G |
| Cadd9 | 大三和弦增加九度音，不要求含七音 | C–E–G–D |

- 和弦名中的 `7` 通常指小七度，不等同于 `maj7`。
- “属七结构”是音程结构名称；在具体调性中是否承担属功能，需看它与主和弦的关系。
- **示例**：C 大调的 G7 为 G–B–D–F，常连接到 C。

参考：[七和弦](https://www.musictheory.net/lessons/45)。

## 转位与斜线和弦

**定义**：转位以实际最低音判定：根音在最低为原位，三音在最低为第一转位，五音在最低为第二转位。

- 斜线左侧是和弦名，右侧是指定低音；如 C/E 表示 C 和弦以 E 为低音。
- 斜线低音也可能不是左侧和弦的组成音，并非所有斜线和弦都是转位。
- 高 G 尤克里里四弦不是最低音，不能只看弦的物理位置判定转位。
- **示例**：E3–G3–C4 是 C 和弦第一转位；高 G 尤克里里的 Am `2000` 实际最低音为 C4。

参考：[三和弦转位](https://www.musictheory.net/lessons/42)。

## 和弦级数与进行

**定义**：和弦进行是和弦按时间的连接顺序；罗马数字表示根音在调内的音级，大、小写常用于区分大小和弦。

- C 大调中：I=C、ii=Dm、iii=Em、IV=F、V=G、vi=Am、vii°=Bdim。
- 罗马数字不限定实际演奏的八度或指法。
- **原创示例**：`| C | Am | F | G7 |`，每和弦一小节 4/4，对应 I–vi–IV–V7；末尾可回 C。

实际按法见[[音乐/尤克里里/和弦与指板|尤克里里和弦表]]；节奏见[[音乐/尤克里里/右手演奏|右手演奏]]。
