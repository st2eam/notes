# 调式与调号

## 主音、调式与调性

**定义**：主音是调性音乐中具有中心地位的音；调式描述围绕主音组织音级的结构；调性说明主音及其调式等组织关系。

- 本文先讨论常见的大调与小调，不把所有音乐都归为大小调。
- 调名包括主音和调式，例如 C 大调、A 小调；只有“C 调”时，常需结合上下文判断含义。
- **示例**：C 大调与 A 自然小调使用同一组基本音，但主音分别为 C 和 A，乐句的重心与和声功能不同。

## 调号

**定义**：调号是谱号后成组出现的升降号，规定相应音名在各八度中的默认升降状态，持续至调号改变。

- 升号顺序：F–C–G–D–A–E–B。
- 降号顺序：B–E–A–D–G–C–F。
- 一个调号不能单独确定大小调，还需结合主音、旋律及和声。
- **示例**：一个升号表示 F 通常奏 F♯，可能对应 G 大调或 E 小调。

| 调号 | 变化音 | 大调 | 关系小调 |
| --- | --- | --- | --- |
| 无升降号 | 无 | C 大调 | A 小调 |
| 1 个升号 | F♯ | G 大调 | E 小调 |
| 2 个升号 | F♯、C♯ | D 大调 | B 小调 |
| 3 个升号 | F♯、C♯、G♯ | A 大调 | F♯ 小调 |
| 1 个降号 | B♭ | F 大调 | D 小调 |
| 2 个降号 | B♭、E♭ | B♭ 大调 | G 小调 |
| 3 个降号 | B♭、E♭、A♭ | E♭ 大调 | C 小调 |

**速查规则**：升号调的大调主音在最后一个升号上方半音；两个及以上降号时，大调主音是倒数第二个降号；一个降号单独记为 F 大调。

参考：[调号](https://www.musictheory.net/lessons/24)、[调号推算](https://www.musictheory.net/lessons/25)。

## 关系大小调与同主音大小调

**定义**：关系大小调共享调号；同主音大小调共享主音。

- 大调的第六级是其关系自然小调的主音；关系小调主音比大调主音低小三度。
- **示例**：C 大调和 A 小调是关系大小调；C 大调和 C 小调是同主音大小调，调号不同。
- 小调的第六、七级常根据和声或旋律需要变化，不代表调号必须随之改变。

相关音阶见[[音乐/基础乐理/音程与音阶|音程与音阶]]。

## 临时变音记号

**定义**：写在音符前的升、降、还原等记号，用于改变该处的记谱音高。

- 常规现代记谱中，效力延续到本小节后续同一谱表、同一音名且同一八度的音；过小节线恢复调号规定。
- 不同八度不自动套用该临时记号；跨小节延音线相连的同一音保持原音高。
- 还原号恢复基本音，不表示“无论什么音都降低半音”；提示性变音记号可能重复提醒已有状态。
- **示例**：G 大调中一个 F4 前写 ♮，本小节后续 F4 通常仍为 F4；下一小节无额外记号时恢复 F♯4。

## 调号、移调与乐器调性

**定义**：移调是按相同音程整体移动音乐，同时保持内部音程关系。

- **示例**：C–F–G–C 整体上移全音，成为 D–G–A–D。
- C 调半音阶口琴的“C”描述基础音位配置，不表示只能演奏 C 大调。
- 尤克里里 GCEA 是空弦调弦，不是歌曲只能使用的调；变调夹改变实际音高，指法名称与实际和弦应分清。

参见[[音乐/半音阶口琴/构造与音位|口琴音位]]、[[音乐/尤克里里/构造与调弦|尤克里里调弦]]。
