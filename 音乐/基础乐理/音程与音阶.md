# 音程与音阶

## 音程的度数与性质

**定义**：音程是两个音之间的音高关系，用“性质＋度数”表示，如大三度、纯五度。

- **度数**：按字母名称计算，起点和终点都计入。C–E 包含 C、D、E，为三度。
- **性质**：结合半音数判定。一、四、五、八度通常以纯音程为基准；二、三、六、七度有大、小之分。
- 纯音程扩大半音成为增音程、缩小半音成为减音程；大音程缩小半音为小音程，小音程再缩小半音为减音程。
- **示例**：C4–E4 是大三度；C4–E♭4 是小三度；C4–D♯4 虽也是三个半音，但字母为二度，称增二度。

| 名称 | 半音数 | 从 C4 上行的例子 |
| --- | --- | --- |
| 纯一度 | 0 | C4–C4 |
| 小二度／大二度 | 1／2 | C4–D♭4／D4 |
| 小三度／大三度 | 3／4 | C4–E♭4／E4 |
| 纯四度 | 5 | C4–F4 |
| 增四度／减五度 | 6 | C4–F♯4／G♭4 |
| 纯五度 | 7 | C4–G4 |
| 小六度／大六度 | 8／9 | C4–A♭4／A4 |
| 小七度／大七度 | 10／11 | C4–B♭4／B4 |
| 纯八度 | 12 | C4–C5 |

**旋律音程**的两音先后出现，**和声音程**的两音同时出现。超过八度的音程称复音程，如 C4–D5 为大九度。

参考：[音程度数](https://www.musictheory.net/lessons/30)、[音程性质](https://www.musictheory.net/lessons/31)。

## 音阶与音级

**定义**：音阶是按音高顺序排列的一组音；音级是音在音阶中的位置，常用罗马数字 I–VII 或“第一级”等表示。

- 音阶公式描述相邻音之间的距离，不是手指形状。
- 下表“全”表示两个半音，“半”表示一个半音；示例均包含上方主音。

| 音阶 | 上行距离公式 | 示例 |
| --- | --- | --- |
| 大调 | 全–全–半–全–全–全–半 | C–D–E–F–G–A–B–C |
| 自然小调 | 全–半–全–全–半–全–全 | A–B–C–D–E–F–G–A |
| 和声小调 | 在自然小调中升高第七级 | A–B–C–D–E–F–G♯–A |
| 古典旋律小调上行 | 在自然小调中升高第六、七级 | A–B–C–D–E–F♯–G♯–A |

- 古典旋律小调下行通常恢复自然小调：A–G–F–E–D–C–B–A。
- 爵士语境中的旋律小调常将上行形式用于两个方向，需要结合风格理解。
- **示例**：G 大调套用大调公式，得到 G–A–B–C–D–E–F♯–G；不能写成两个 G 而省略 F 音名。

参考：[大调音阶](https://www.musictheory.net/lessons/21)、[三种小调音阶](https://www.musictheory.net/lessons/22)。

## 半音阶与五声音阶

**定义**：半音阶以半音连续连接；大调五声音阶取大调的第 1、2、3、5、6 级。

- C 大调五声音阶：C–D–E–G–A；A 小调五声音阶：A–C–D–E–G。
- 半音阶上行常用升号、下行常用降号，但具体拼写仍取决于音乐语境。
- **示例**：C4–C♯4–D4–D♯4–E4 为半音阶片段；C4–D4–E4–G4–A4 为五声音阶片段。
