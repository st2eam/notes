# 音乐

面向基础学习的技术笔记，按概念、乐器音位与演奏动作组织。默认十二平均律；中央 C 为 C4。口琴采用十二孔 C 调独奏音阶排列，尤克里里采用高 G 调弦。

## 建议阅读顺序

先阅读基础乐理的音高与音名、节奏与节拍、记谱法，再进入对应乐器的构造与基本演奏。音程、调号和和弦可在需要时回查；每个示例的拍值、音高与操作记号以其局部说明为准。

## 编写约定

- 每个知识点说明定义、关键要点与示例；动作类内容补充操作和常见错误。
- 口琴操作写明孔号、吹吸与按键状态；尤克里里四位品位数字按四弦至一弦排列。
- 音位、和弦和节奏示例用于查阅，不是完整歌曲编配；不同型号或教材记号先查其图例。
