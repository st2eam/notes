# 构造与调弦

## 适用范围与构造

**定义**：尤克里里是一种常见四弦拨弦乐器，按弦改变有效弦长，右手使琴弦振动发声。

本文默认右手演奏，使用 soprano、concert 或 tenor 常见的 GCEA 调弦；baritone 常用 DGBE，不直接套用本组空弦音高和和弦名称。

| 部件 | 作用 |
| --- | --- |
| 琴体、面板、音孔 | 支撑并辐射琴弦振动形成的声音 |
| 琴颈、指板 | 提供左手按弦区域 |
| 品丝 | 按弦时界定有效弦长，相邻品对应半音 |
| 上弦枕（nut） | 确定空弦在琴头侧的支点 |
| 下弦枕（saddle） | 确定琴桥侧的振动支点 |
| 琴桥 | 固定或连接琴弦，并把振动传到面板 |
| 弦钮（调音器） | 调整琴弦张力，从而改变音高 |

**示例**：按一弦第三品时，发声有效弦长以第三品丝为一侧支点，得到比空弦 A4 高三个半音的 C5。

## 弦号与高 G 调弦

**定义**：按正常演奏姿势，从靠近地面的一侧起编号，一弦至四弦；高 G 调弦的四弦比三弦高，属于回入式调弦。

| 弦号 | 右手持琴时的位置 | 高 G 空弦音高 |
| --- | --- | --- |
| 四弦 | 靠近脸部／天花板一侧 | G4 |
| 三弦 | 四弦下一根 | C4 |
| 二弦 | 三弦下一根 | E4 |
| 一弦 | 靠近地面一侧 | A4 |

- 本组和弦数字一律按**四弦→一弦，即 G–C–E–A**排列；这与弦号从 1 开始数的方向不同。
- 高 G 的最低空弦音是三弦 C4，不能按物理位置从上到下理解为音高递增。
- **示例**：空弦从四弦拨到一弦，实际听到 G4–C4–E4–A4，第二个音反而更低。

参考：[Fender：调弦与弦的对应](https://www.fender.com/articles/setup/how-to-tune-a-ukulele)。

## 低 G 调弦

**定义**：低 G 将四弦改为 G3，其余三根保持 C4、E4、A4。

- 从四弦到一弦变成 G3–C4–E4–A4，空弦音高依次上升。
- 常用和弦的品位形状通常仍适用，但实际声部排列、最低音和旋律音域会变化。
- 更换为适配的低 G 弦；不把高 G 弦强行调高或用错误八度追逐音名。
- **示例**：同样弹 C 和弦 `0003`，高 G 为 G4–C4–E4–C5，低 G 为 G3–C4–E4–C5。

![高 G 与低 G 的四根空弦音高；高 G 最低音在三弦，低 G 最低音在四弦。](/music/diagrams/ukulele-tuning.svg)

## 调弦方法

**定义**：调弦是将空弦调到目标音高，并反复复核各弦。

1. 选择调音器的尤克里里模式，或能显示八度的半音调音模式。
2. 每次只拨一根空弦，对照弦号与目标音；确认音名和八度，尤其是 G4／G3。
3. 小幅转动对应弦钮，偏低则适度升高，偏高则降低；不要按固定顺／逆时针规则套用所有弦钮。
4. 四根依次调整后再检查一轮，新弦在使用初期可能需要多次复调。

**示例**：高 G 配置的四弦目标是 G4，只显示“G”的调音器无法单凭字母排除八度错误，可结合已知参考音判断。

## 持琴与品位

**定义**：第 n 品指按下后以第 n 根品丝为发声支点的区域；0 表示空弦。

- 琴体由前臂与身体稳定支撑，左手不必死抓琴颈；右手腕保持自然活动。
- 手指落在目标品格内、靠近琴桥方向的品丝后侧，避免正压品丝或离品丝太远。
- **示例**：一弦三品使用无名指按实，逐根检查没有碰到二弦；只用让音清楚所需的力度。
