# DNA双螺旋结构

**DNA（脱氧核糖核酸）双螺旋**由两条方向相反、碱基互补的多核苷酸链组成。两条链的糖—磷酸骨架位于外侧，碱基位于内侧并相互配对，整体绕同一条轴盘旋。细胞中常见的 B 型 DNA 是右手双螺旋。

DNA 的碱基排列顺序储存遗传信息；双链互补关系使每条链都能作为合成另一条链的模板。

## 核苷酸与单链结构

DNA 的基本单位是[[生物学/核苷酸|脱氧核糖核苷酸]]，由磷酸、2-脱氧核糖和含氮碱基组成。糖的碳原子用 1′、2′、3′、4′、5′ 编号，以区别于碱基中的原子编号。

- 碱基连接在糖的 1′ 碳上。
- 脱氧核糖的 2′ 碳上为氢；[[生物学/RNA|RNA]] 的核糖在这一位置具有羟基。
- 相邻核苷酸通过 **3′—5′ 磷酸二酯键**连接：磷酸把前一个糖的 3′ 位氧与后一个糖的 5′ 位氧连接起来，形成重复的糖—磷酸骨架。

DNA 有四种常见碱基：

| 类别 | 碱基 | 缩写 | 环结构 |
| --- | --- | --- | --- |
| 嘌呤 | 腺嘌呤 | A | 双环 |
| 嘌呤 | 鸟嘌呤 | G | 双环 |
| 嘧啶 | 胸腺嘧啶 | T | 单环 |
| 嘧啶 | 胞嘧啶 | C | 单环 |

一条 DNA 链具有**方向性**，序列通常按 **5′→3′**方向书写。对于常规线性 DNA，3′ 端具有游离的 3′ 羟基，5′ 端可以带磷酸或羟基；方向名称取决于糖的碳编号，不取决于书写时位于左侧还是右侧。环状 DNA 没有游离末端，但链仍有方向性。

## 反向平行与互补配对

两条 DNA 链以**反向平行**方式排列：沿同一空间方向观察，一条是 5′→3′，另一条就是 3′→5′。

```text
5′—A G T C C A—3′
   | | | | | |
3′—T C A G G T—5′
```

这是碱基配对关系的平面示意，省略了糖—磷酸骨架和螺旋扭转。

标准 Watson–Crick [[生物学/碱基互补配对|碱基互补配对]]遵循：

- **A—T**：形成两个氢键。
- **G—C**：形成三个氢键。

每个标准碱基对由一个嘌呤和一个嘧啶组成，在正常双螺旋中保持相近的宽度。配对特异性同时依赖碱基的几何形状和氢键供体、受体的位置。

对于上面的第一条链 `5′-AGTCCA-3′`，按相同的 5′→3′ 书写习惯，另一条链应写成 `5′-TGGACT-3′`，称为原序列的**反向互补序列**。只把字母逐个换成互补碱基，还没有完成方向转换。

对于完全遵循标准配对的双链 DNA，把两条链合计时，有 $A=T$、$G=C$，因而嘌呤总量等于嘧啶总量。这一数量关系不要求单独一条链也满足 $A=T$ 或 $G=C$。

## B 型 DNA 的空间结构

B 型 DNA 是充分水合、接近生理条件下最常见的双螺旋构象，其典型参数为：

| 参数 | 典型值或特征 |
| --- | --- |
| 螺旋方向 | 右手螺旋 |
| 螺旋直径 | 约 2 nm |
| 每圈碱基对数 | 平均约 10.5 bp |
| 相邻碱基对的轴向间距 | 约 0.34 nm |
| 螺距，即一圈沿轴前进的距离 | 约 3.4～3.6 nm |
| 碱基对平面 | 大致垂直于螺旋轴，并逐层堆叠 |

这些数值是近似值，会随碱基序列、溶液条件和扭转状态变化。教科书中“每圈约 10 个碱基对、螺距约 3.4 nm”是常见的简化描述。

两条骨架在螺旋表面形成宽窄不同的**大沟**和**小沟**。沟槽来自碱基对中连接两条糖—磷酸骨架的位置并非正好相对。

大沟和小沟暴露出不同的化学基团排列。许多 DNA 结合蛋白可通过这些排列识别序列，而不需要先把双链完全解开；大沟通常能提供更丰富的碱基对识别信息，小沟的形状和电性也参与识别。

## 双螺旋的稳定机制

双螺旋的稳定来自多种相互作用，不能只归结为“碱基之间存在氢键”。

| 因素 | 作用 |
| --- | --- |
| 碱基配对的氢键 | 参与互补碱基的特异性识别与配对 |
| 碱基堆积 | 相邻碱基之间的堆积相互作用对双螺旋稳定有重要贡献，与碱基序列有关 |
| 水合与疏水效应 | 碱基堆在内部、骨架接触水的排列与溶剂环境共同影响稳定性 |
| 离子屏蔽 | 磷酸基团在生理 pH 下带负电，阳离子可减弱骨架之间的静电排斥 |

同一条链中的核苷酸依靠共价的磷酸二酯键相连；两条链之间主要依靠非共价相互作用结合。双链可以局部打开，同时保留各自骨架的连续性，这是复制和转录得以进行的结构基础。

在长度、盐浓度等条件相近时，GC 含量较高的 DNA 通常具有较高的熔解温度。但稳定性还取决于相邻碱基的堆积、序列、错配和溶液环境，不能仅按氢键数目判断。

## 结构与遗传功能

### 信息储存与序列识别

遗传信息主要体现在碱基序列中。不同序列可以编码 RNA 和蛋白质，也可以参与基因表达调控或承担结构功能；DNA 并非所有片段都编码蛋白质。

双链骨架的规则性使不同序列能够维持相似的总体结构，而沟槽暴露的化学特征又允许蛋白质区分不同序列。

### 半保留复制

[[生物学/DNA复制|DNA 复制]]时，双链解开后，每一条亲代链都可作为模板，按照互补配对规则合成新链。复制完成后，每个子代双链 DNA 都含有一条亲代链和一条新合成链，称为**半保留复制**。

DNA 聚合酶把新的核苷酸接到正在延伸的链的 3′ 羟基上，因此新链始终沿 **5′→3′**方向延长。由于两条模板反向平行，在常规复制叉中：

- **前导链**沿复制叉推进方向连续合成。
- **后随链**通过多个冈崎片段分段合成，再由连接酶连接。

前导链与后随链的合成方向都为 5′→3′。复制时通常需要引物；互补结构解释了模板关系，并不意味着 DNA 可以脱离酶和底物自行完成复制。

### 转录与局部解链

[[生物学/转录|转录]]时，RNA 聚合酶读取其中一条 DNA 模板链，沿 5′→3′ 方向合成 RNA。DNA 通常只在转录区域局部打开，随后重新形成双螺旋。RNA 中用尿嘧啶 U 与模板上的 A 配对。

## 变性与复性

**DNA 变性**指双螺旋结构受到破坏、两条链分离或局部解开的过程，常见诱因包括升温和极端 pH。在通常的温和热变性条件下，变化主要涉及链间配对与堆积，不是切断糖—磷酸骨架。

变性时，DNA 在 260 nm 处的紫外吸收通常增加，称为**增色效应**。实验中的熔解温度 $T_m$ 通常指熔解转变达到一半时的温度；它与序列、长度、盐浓度、错配以及特定体系中的链浓度有关。

条件恢复合适后，互补单链可以重新配对形成双链，称为**复性**或**退火**。这一性质是 PCR 中变性和引物退火、核酸杂交等技术的基础。

## A、B、Z 三种典型构象

DNA 的双螺旋可以采用不同构象，B 型不是唯一形式。

| 构象 | 螺旋方向 | 每圈碱基对数 | 典型特征与条件 |
| --- | --- | --- | --- |
| A-DNA | 右手 | 约 11 | 比 B 型更短、更粗；较低水合条件下可出现，双链 RNA 和 DNA—RNA 杂交双链通常也呈 A 型或接近 A 型的几何构象 |
| B-DNA | 右手 | 约 10.5 | 充分水合条件下最常见的 DNA 构象 |
| Z-DNA | 左手 | 约 12 | 骨架呈锯齿状，某些嘌呤与嘧啶交替的序列较易形成；其形成受盐浓度、负超螺旋及蛋白质等因素影响 |

这些构象描述的是双链本身的局部几何结构。**超螺旋**则描述双螺旋轴进一步盘绕形成的更高层次结构，二者不是同一概念；DNA 缠绕组蛋白形成核小体也属于更高层次的组织。

## 结构发现与实验证据

- **查加夫规律**：双链 DNA 中 A 与 T、G 与 C 的数量大致相等，为互补配对提供了组成上的约束。
- **X 射线纤维衍射**：罗莎琳德·富兰克林、雷蒙德·戈斯林以及莫里斯·威尔金斯等人的研究，为螺旋结构和分子尺寸提供了关键证据。
- **1953 年双螺旋模型**：詹姆斯·沃森和弗朗西斯·克里克结合衍射证据、碱基组成及化学结构限制，提出反向平行、互补配对的双螺旋模型。
- **1958 年梅塞尔森—斯塔尔实验**：利用氮同位素标记和密度梯度离心，为 DNA 的半保留复制提供证据；这是对复制方式的验证，与 1953 年的结构建模属于不同的问题。
