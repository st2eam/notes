# 长期合作、声誉与机会

如果合作会反复发生，今天是否履约也会影响下次交易的条件。纳瓦尔用熟悉的交易伙伴说明，长期可靠的记录能减少反复审查和谈判，让双方更敢承担有共同收益的项目。用[[经济学/博弈论/重复博弈与无名氏定理|重复博弈]]检验合作条件时，要看后续合作有没有足够价值、过去行为能否被观察并得到回应。

## 责任如何成为可信记录

明确谁能作决定、谁对交付结果负责、谁承担失败的损失。可核查的交付记录比宣称愿意负责更能帮助合作方形成判断。[[经济学/博弈论/声誉效应|声誉效应]]解释了历史行为怎样改变别人对你的预期。把结果责任分清，也能看见出资方和执行者在哪些地方有不同激励，可参阅[[经济学/博弈论/机制设计与显示原理#委托代理问题|委托代理问题]]。

## 四种获得机会的情形

1. **偶然遇到**。机会的出现与你先前的行动无关，例如意外收到一份邀约。
2. **主动增加接触**。接连做原型、采访和试验，使自己遇到更多反馈与合作对象。
3. **及时辨认**。积累领域经验后，更容易察觉一项新变化能解决哪个旧问题。
4. **让他人想起你**。具备稀缺能力且有交付记录，有需求的人更容易主动来找你。

在书中的深海打捞例子里，发现沉船带有偶然性，发现者决定求助哪位潜水员，则受潜水员的能力和声誉影响。对应到日常工作，可以区别机会是否发生、自己能否识别它、别人会不会把它交给自己。三件事受不同条件影响。

积累信任需要时间。续不续约依然取决于未来的交易条件、对方近期的行为及替代选择；已经投入的时间可以按[[经济学/沉没成本|沉没成本]]单独判断。
