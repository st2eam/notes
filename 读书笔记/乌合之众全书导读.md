# 乌合之众全书导读

勒庞从一个问题出发：为什么人在共同处境中，会说出平时不赞同的话，或做出独处时不会做的事？第一卷提出「心理群体」及其心理特征，第二卷追踪群体意见怎样积累、传播和改变，第三卷转向陪审团、选民、议会等组织，结束章把讨论推到文明兴衰。以下章节以戴光年译本为准。

## 第一卷 群体心理

1. 群体的一般特征 → [[心理学/社会心理学/心理群体|心理群体]]。何时才算形成群体？勒庞怎样解释行为趋同？
2. 群众的情感和道德观 → [[心理学/社会心理学/群体中的见证情感与道德|群体中的见证、情感与道德]]。相似的目击报告有几个独立来源？共同情感何时促成互助？
3. 群体的观念、推理与想象力 → [[心理学/社会心理学/群体的观念推理与想象力|群体的观念、推理与想象力]]。醒目的事例和持续发生的风险，为什么造成不同印象？
4. 群体信仰所采取的宗教形式 → [[心理学/社会心理学/群体信念的宗教形式|群体信念的宗教形式]]。作者怎样用崇拜、服从和排斥异议比较宗教与政治信念？

## 第二卷 群体的意见与信念

1. 群体的意见与信念中的间接因素 → [[心理学/社会心理学/群体意见的形成条件|群体意见的形成条件]]。传统、制度和教育等怎样为后来发生的事准备条件？
2. 群体意见的直接因素 → [[心理学/社会心理学/形象词语与群体意见|形象、词语与群体意见]]。什么触发即时反应？什么经验可能改变原有意见？
3. 群体领袖及其说服的手法 → [[心理学/社会心理学/群体领袖重复与声望|群体领袖、重复与声望]]。组织、反复接触和传播者的声望分别影响什么？
4. 群体的信念与意见的变化范围 → [[心理学/社会心理学/群体信念的稳定与舆论变动|群体信念的稳定与舆论变动]]。短期舆论和长久信念以什么速度改变？

## 第三卷 不同群体的分类及其特点

1. 群体的分类 → [[心理学/社会心理学/勒庞的群体分类|勒庞的群体分类]]。成员构成、组织名称和联结纽带分别用来区分什么？
2. 被称为犯罪群体的群体 → [[心理学/社会心理学/集体暴力中的责任与自我辩护|集体暴力中的责任与自我辩护]]。参与者为何会把造成伤害解释为履职？
3. 刑事案件的陪审团 → [[心理学/社会心理学/陪审团中的判断与证词|陪审团中的判断与证词]]。证词、情感反应和程序怎样进入裁决？
4. 选民群体 → [[心理学/社会心理学/选民群体与政治判断|选民群体与政治判断]]。同一句口号背后，选民想实现的安排可能有多不同？
5. 议会 → [[心理学/社会心理学/议会讨论与群体决策|议会讨论与群体决策]]。哪些立场在入场前就已确定，哪些会被发言和修正案改变？
6. 结束章「民族存亡的关头」 → [[心理学/社会心理学/共同理想与文明兴衰|共同理想与文明兴衰]]。作者用了什么假设，把共同信念与文明的凝聚联系起来？

## 与后来的研究对读

书中的历史轶事说明勒庞如何解释群众行为，不能单凭轶事确定成因。作者关于民族性格遗传的说法带有十九世纪的理论背景。读具体案例时，可以先辨认观察到的变化，再找可比较的条件：

- **情绪和判断**：有人变得和身边人一样紧张，或在公开场合改口？[[心理学/社会心理学/情绪感染|情绪感染]]和[[心理学/社会心理学/从众|从众]]讨论的结果不同。
- **匿名和身份**：成员在哪些方面难以被辨认？他们将谁视为「我们」？[[心理学/社会心理学/去个体化|去个体化]]与[[心理学/社会心理学/社会认同|社会认同]]提供了不同的考察角度。
- **熟悉和极端**：一句话因重复变得可信，或一群人讨论后沿原有方向走得更远？可以分别参看[[心理学/认知心理学/虚幻真相效应|虚幻真相效应]]和[[心理学/社会心理学/群体极化|群体极化]]。
