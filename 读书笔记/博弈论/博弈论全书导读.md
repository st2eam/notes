# 博弈论基础与阅读路线

**博弈论**研究参与者之间存在相互影响的决策。分析对象包括竞争、合作、谈判，以及改变行动激励的规则。

基础任务是建立一个明确模型：哪些人能作出选择、每个人可以做什么、不同选择带来什么收益，以及行动时掌握什么信息。

## 1. 基本术语

| 术语 | 定义 | 示例 |
| --- | --- | --- |
| 参与者 | 能作出选择的人或组织 | 消费者、商家、团队 |
| 行动 | 某个决策时刻的具体选择 | 当前是否降价 |
| 策略 | 对所有相关可能情况规定行动的完整计划 | 对手降价则跟进，否则保持价格 |
| 收益 | 对结果的评价，用于比较不同选择 | 利润、时间、风险或公平感 |
| 最优回应 | 给定他人策略时，能够最大化自身收益的策略 | 对手定价后选择最有利的价格 |
| 纳什均衡 | 各方策略互为最优回应的组合 | 无人能通过单方改变策略提高收益 |

[[读书笔记/博弈论/策略式博弈和纳什均衡|纳什均衡]]描述稳定性。均衡不必有效率或公平，也可能不唯一。实际互动是否到达某个均衡，还需要学习和协调等解释。

## 2. 模型分类

### 行动顺序

- **静态模型**：行动时无法观察其他人当前的选择。钟表时间不必完全相同。
- **动态模型**：决策有先后关系，需要规定每一步能观察哪些历史。

### 信息结构

- **完全信息**：参与者知道彼此的收益规则、成本或偏好等相关特征。
- **不完全信息**：部分特征为私人信息，需要用类型及其概率分布建模。
- **完美信息**：每次决策都知道此前发生的行动。

完全信息与完美信息关注不同问题。知道对手的收益，不等于能够看见对手刚才的行动。

| 模型类型 | 常用分析工具 | 示例 |
| --- | --- | --- |
| 静态、完全信息 | [[读书笔记/博弈论/策略式博弈和纳什均衡|纳什均衡]] | 同时决定合作或背叛 |
| 动态、完全信息 | [[读书笔记/博弈论/扩展式博弈与子博弈完美均衡|子博弈完美均衡]] | 一家企业先定产量，另一家观察后回应 |
| 静态、不完全信息 | [[读书笔记/博弈论/贝叶斯博弈与贝叶斯均衡|贝叶斯均衡]] | 投标者只知道自己的估值 |
| 动态、不完全信息 | [[读书笔记/博弈论/均衡的精炼|策略与信念的精炼]] | 买方拒绝报价，卖方调整后验判断 |

这些分类用于选择工具；具体模型仍需给出观察规则、行动集合和收益函数。

## 3. 通用分析流程

1. **列出参与者与策略**：明确谁能影响结果，以及实际可用的选项。
2. **定义收益**：写出各选择组合对应的得失，注明比较口径。
3. **标注时序与信息**：规定行动顺序、可观察历史和私人信息。
4. **求最优回应**：固定其他人的策略，分别比较自身选择。
5. **验证均衡**：检查是否存在提高收益的单方偏离。
6. **验证后续可信性**：动态模型还要检查未实际发生局面中的计划。
7. **检查边界**：改变期限、信息或规则，观察结论是否保留。

**建模示例**：两家咖啡店选择是否降价。一次互动需要比较当期利润；长期互动还需计算降价引起的未来回应。[[读书笔记/博弈论/重复博弈与无名氏定理|重复博弈]]用历史策略和贴现收益表示这种变化。

## 4. 公式阅读方法

每个公式先确定三个要素：符号表示什么、比较哪些收益、结论依赖哪些假设。

| 公式类型 | 阅读重点 |
| --- | --- |
| 最优回应条件 | 其他人的策略固定后，自身怎样选择 |
| 期望收益 | 各种可能结果的收益及其概率权重 |
| 贴现收益 | 不同时点的收益怎样换算到同一时点 |
| 激励约束 | 遵守计划的收益是否至少等于偏离收益 |

混合策略与类型模型使用概率加权比较，计算基础可参阅[[数学/概率与实验/桌游中的概率与统计|期望值计算]]。数值例子中的门槛属于给定模型；一般结论需要连同条件一起使用。
