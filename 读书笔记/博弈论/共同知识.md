# 共同知识

**共同知识**要求某个事实被所有人知道、所有人知道所有人知道，并包含继续递推的全部相互知道层级。

它描述信息结构，而不只描述信息是否发送成功。公开宣布、确认方式和对规则的共同理解，都会影响这种结构。

## 1. 知识与信息结构

### 可能状态与个人知识

形式模型常把各种可能情况称为世界或状态。一个人的信息决定他还不能排除哪些状态。

如果他认为仍有可能的所有状态都包含某个事实，就说他知道这个事实。例如，看见乙有红点的人，排除了“乙没有红点”的所有状态，却未必能排除“自己没有红点”。

不同人的信息范围交织起来，形成对他人知识的高阶认识。私人信息的类型表示与此相关，见[[读书笔记/博弈论/贝叶斯博弈与贝叶斯均衡|类型与信息结构]]。

### 相互知道的层级

**层级示例**：以“会议改到三点”为事件。

| 层级 | 含义 |
| --- | --- |
| 个人知识 | 某个人知道会议改期 |
| 相互知识 | 每个人都知道会议改期 |
| 二阶相互知识 | 每个人知道所有人都知道会议改期 |
| 更高层级 | 继续加入对他人知识的认识 |
| 共同知识 | 所有相互知道层级都成立 |

共同知识要求所有这些层次都成立。“大家都知道”通常只表达其中较低的一层。

现实中，可靠的公开宣布能帮助形成这种结构。但若有人可能没听见、大家不确定谁在场，就不能仅凭“已经公开”断言共同知识成立。

## 2. 示例：红点与公开宣布

**模型设定**：

- 甲、乙额头可能有红点，每个人只能看见对方。
- 规则与正确推理是共同理解的。
- 主持人可信地公开宣布：至少一人有红点。

- 每轮能够确定自己有红点的人同时举手，举手结果公开可见。
- 实际状态为双方都有红点。

**推导**：

第一轮，甲看见乙有红点，无法确定自己有没有。乙也一样，所以两人都不举手。

第二轮，甲根据乙未举手排除自己没有红点的可能：若甲没有红点，乙第一轮就能根据公开宣布确定自己有红点，并举手。乙作出同样推断。

**结果**：双方在第二轮同时举手。

**信息作用**：公开宣布将事实变成相互推理的共同依据。即使实际状态下每人已经看到红点，宣布仍会改变关于他人知识的高阶判断。

这个结果依赖公开且同时的轮次、可信宣布、正确推理，以及这些条件本身被共同理解。去掉这些条件，沉默未必还能传递同样信息。

## 3. 共同理性与策略剔除

剔除一个明显吃亏的选项，只要求该参与者理解收益并选择最优回应。再根据这次剔除排除自己的选项，则要求自己知道对方会这样推理。

反复剔除时，就需要更多层关于理性的认识。[[读书笔记/博弈论/重复严格优势可理性化与相关均衡|可理性化与策略剔除]]因此与共同知识紧密相关。

现实中，沟通、确认和公开记录不仅传递事实，还会改变“谁知道别人知道什么”。这也是公开协调有时能改变结果的原因。

## 4. 共同先验的相关结果

### 后验一致性

奥曼的一致性定理说明：在标准的贝叶斯知识模型中，若双方具有共同先验，而且对某事件的后验概率成为共同知识，这些后验就必须相同。

重点在条件：共享先验、正确条件化、各自后验成为共同知识。它不表示现实中理性的人不能有不同意见；不同先验、不同模型或没有完全公开判断，都可能保留分歧。

直觉是，对方的概率判断本身也是信息。若双方充分理解彼此判断背后的信息范围，就不能把它当成与自己的更新无关的消息。

### 无交易结果

相关的无交易结果说明：在共同先验、适当理性与知识条件，以及初始配置已事前有效等假设下，单靠私人信息差异不能普遍创造双方都愿意接受的纯投机交易。

共同先验、知识与无交易结果之间的联系，可参阅 [Jonathan Levin 的知识与均衡讲义](https://web.stanford.edu/~jdlevin/Econ%20286/Knowledge%20and%20Equilibrium.pdf)。这并不否认现实交易。不同消费需求、风险分担、流动性需求或不同先验，都可能使交易合理。理论限制的是特定模型中的信息投机，不能直接写成“信息不对称时不会交易”。

## 5. 近似共同知识与稳健性

对事实的高置信度，不自动等于各层相互信念都具有高置信度。电子邮件协调问题展示了这种差别：消息可能丢失，确认也可能丢失，最后收到确认的人还无法确定对方是否知道确认已经到达。

因此，一条消息很可靠，与各层相互信念都足够可靠，并不是同一个条件。近似共同知识需要对这些层级作严格定义；仅让每个人对事实赋予很高概率，未必能保留原来的均衡。

信息结构的小变化可能改变预测，和[[读书笔记/博弈论/策略式博弈高级专题|收益扰动下的均衡稳健性]]一起提醒我们：模型的稳定性不只取决于数字，还取决于人们如何理解彼此的信息。

**信息检查项目**：事实是否传达、是否确认收到、确认是否公开，以及各方是否理解同一套规则。
