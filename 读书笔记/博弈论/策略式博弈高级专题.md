# 策略式博弈高级专题

策略式博弈的进阶分析主要考察四项性质：均衡是否存在、共有多少个均衡、收益变化后是否保留附近均衡，以及模型是否具有可利用的特殊结构。

这些性质用于评估预测的可靠性。存在一个均衡，不等于均衡唯一、容易计算或能够被实际互动选中。

## 1. 均衡存在性

[[读书笔记/博弈论/策略式博弈和纳什均衡|纳什均衡]]的存在定理保证有限博弈至少有一个混合均衡，但它不保证纯策略均衡，也不保证唯一性或容易计算。

当行动可以连续变化，例如价格或产量，通常还要检查行动集合是否有界并包含边界、收益是否连续，以及收益对自己的选择是否具有适当的凹性性质。

这些条件帮助确保最优回应存在，并能找到彼此相容的回应。若缺少它们，需要其他存在性定理，不能因为曲线看上去平滑就认定有解。

## 2. 均衡数量

### 奇数性定理

奇数性定理指出：对一般位置的有限博弈，全部纳什均衡的数量是有限且为奇数。一般位置意味着排除某些精确并列或其他退化情况。

这里的“几乎所有”是数学意义上的典型性，并不是通过调查发现大多数现实博弈都有奇数个均衡。

它也不表示只能有一个均衡，更不表示只数纯策略均衡就一定是奇数。特殊收益结构可能有偶数个均衡或连续一整族均衡。

### 示例：两个纯均衡与一个混合均衡

**模型设定**：两个参与者进行如下协调博弈。

| 甲的选择 / 乙的选择 | 左 | 右 |
| --- | --- | --- |
| 上 | 3，2 | 0，0 |
| 下 | 0，0 | 2，3 |

有两个纯策略均衡：“上、左”和“下、右”。它还存在一个混合均衡。

设乙选左的概率为 $q$。为了让甲对上下无差异，需要 $3q=2(1-q)$，所以 $q=2/5$。设甲选上的概率为 $p$。为了让乙对左右无差异，需要 $2p=3(1-p)$，所以 $p=3/5$。

**计算结果**：该博弈有两个纯策略均衡和一个混合均衡，共三个。均衡数量统计应同时包括纯策略与混合策略。

## 3. 收益扰动与本质均衡

**收益稳健性**要求小幅改变收益后，仍存在靠近原均衡的均衡。原策略点不必保持完全不变。

如果任意足够小的收益扰动都满足这一要求，就称原均衡为本质均衡。它强调附近解的保留，并不要求解完全不动，也不要求其他均衡消失。

直觉上，严格均衡更容易保持，因为每个人的当前选择与替代选项之间有明确收益差。大量无差异和刚好相等的边界条件，往往值得做敏感性检查。

同类问题还可以延伸到失误方式与信息结构，分别见[[读书笔记/博弈论/均衡的再精炼与前向归纳|策略稳定性]]和[[读书笔记/博弈论/共同知识|共同知识与信息变化]]。

## 4. 不连续收益

价格竞争提供一个直观例子：两家卖同质产品的商家报价相同，可以平分顾客；其中一家降价一分钱，却可能吸引全部顾客。价格变化很小，销量和利润却跳跃变化。

这种不连续意味着普通的连续收益存在性条件不能直接使用，但不表示一定没有均衡。有些模型仍有解，需要结合具体规则和适当的存在性条件判断。

## 5. 策略互补与超模博弈

**策略互补**表示：他人提高行动水平后，自身提高行动的吸引力也上升。例如，团队学习某项协作技能的人越多，另一个成员学习该技能的协作收益可能越大。

超模博弈把这种互补性写成数学结构：策略能够按大小比较，自身各行动维度具有适当互补性，且自身行动与他人行动满足递增差异等条件。

**示例设定**：两人选择是否学习一项协作技能，学习成本为 2，只有两人都学会时，学习者才获得价值 4。对方不学时，自己学习净收益为 -2，不学为 0；对方学习时，自己学习得 2，不学为 0。

“都不学”与“都学习”都是均衡。对方行动水平提高时，自身也更愿意提高行动水平，这种结构自然产生低水平和高水平的协调结果。

在合适的有序策略空间和正则条件下，超模博弈有纯策略均衡，并有最小、最大纯策略均衡。这有助于研究比较静态：外部条件改善后，行动和均衡边界怎样变化。它不保证所有学习过程都收敛，也不意味着可理性化策略集合与均衡集合总是相同。

## 6. 模型验证要点

1. 明确存在性结论针对纯策略还是混合策略。
2. 检查是否存在其他均衡。
3. 小幅改变收益，检查附近结果是否保留。
4. 核实连续性、互补性等结构假设。

这些检查能帮助区分“模型确实支持这个结论”与“这个结论只在一组特殊设定下成立”。
