# 扩展式博弈与子博弈完美均衡

**扩展式博弈**用博弈树表示行动顺序、信息和收益。**子博弈完美均衡**要求策略在整个博弈及每个子博弈中都构成纳什均衡。

分析重点是后续计划的可信性：即使某个局面没有沿均衡路径发生，计划在那个局面下仍应是最优回应。

## 1. 基本概念

### 节点、信息集与策略

| 博弈树要素 | 含义 |
| --- | --- |
| 决策节点 | 当前轮到谁行动 |
| 分支 | 当前可以选择的行动 |
| 终点 | 各方的最终收益 |
| 自然节点 | 需求高低等随机事件 |

**信息集**表示行动者无法区分的一组节点。行动者无法观察对手的此前选择时，可能不能确定当前节点。同一信息集内的行动计划不能依赖无法观察的差别。

策略是完整的行动计划，不只包含实际发生的那条路径。比如一家店的策略应说明“对手进入时怎么办”和“对手没有进入时怎么办”，即使最后只有一种情况发生。

### 子博弈与子博弈完美性

**子博弈**是一段能独立分析的后续博弈。它从一个单节点信息集开始，包含全部后续节点，而且不能切开任何信息集。

**子博弈完美均衡**要求策略在整个博弈以及每个子博弈中都构成纳什均衡。因此，即使某个局面最终没有发生，计划在那个局面下仍然要经得住最优回应检查。

子博弈完美性排除依赖非最优后续行动的威胁。某项威胁要成立，需要其执行具有收益优势，或存在可信承诺。

## 2. 示例：市场进入与逆向归纳

### 模型与可信性检查

**模型设定**：新店先选择进入或不进入；发生进入后，在位店选择和平竞争或价格战。收益如下。

| 结果 | 新店收益 | 在位店收益 |
| --- | --- | --- |
| 不进入 | 0 | 5 |
| 进入、和平竞争 | 2 | 2 |
| 进入、价格战 | -1 | -1 |

**纳什均衡检查**：若新店相信进入后会发生价格战，则选择不进入。把策略写成“新店不进入，在位店遇到进入就打价格战”，这个组合是纳什均衡：新店按预期进入会亏损；在位店单独改计划也不影响未进入的实际结果。

**可信性检查**：发生进入后，在位店和平竞争得 2，价格战得 -1。因此价格战不是后续最优回应，该威胁不可信。

### 逆向归纳

对有限、完美信息博弈，从最后的决策节点向前求解。以上述进入模型为例：

1. 已经发生进入时，和平竞争优于价格战。
2. 新店预见这一点，就比较进入后的 2 与不进入的 0。
3. 新店选择进入，在位店选择和平竞争。

上述方法称为**逆向归纳**，也常称逆向递归：先确定后续选择，再把其结果带回较早的决策。有限、完美信息的博弈可以这样逐步求解；若某一步有并列最优选择，可能得到多个结果。

## 3. 示例：先行产量选择

**模型设定**：先行选择可以影响后行动者的最优回应。例中，两家企业销售同质产品，总产量为 $q_1+q_2$，价格为 $12-q_1-q_2$，生产成本为零。

若同时选产量，每家均衡产量是 4，利润各为 16。若甲先选产量，乙观察后再选，乙的最优回应是 $q_2=\max\{0,(12-q_1)/2\}$。甲考虑这一回应后选择 6，乙选择 3，利润分别为 18 和 9。

**结论与条件**：可观察的先行选择在该产量模型中产生承诺优势。先动优势不是一般性结论。有些博弈中，等待能带来更多信息或保留调整空间。行动时机的其他例子见[[读书笔记/博弈论/多阶段可观察行动博弈的应用|多阶段博弈的应用]]。

## 4. 适用边界

当信息集把多个节点连接起来时，可独立切出的子博弈可能很少。某些信号博弈甚至没有真子博弈，因此子博弈完美性无法约束所有关键的后续选择。

这不意味着所有不完全信息博弈都没有子博弈，而是提醒我们：信息结构会限制这个概念的筛选能力。此时通常需要同时检查策略和信念，见[[读书笔记/博弈论/均衡的精炼|均衡的精炼]]。

实际分析时，先用[[读书笔记/博弈论/策略式博弈和纳什均衡|纳什均衡]]检查单方偏离，再沿博弈树检查每一段后续计划是否可信。
