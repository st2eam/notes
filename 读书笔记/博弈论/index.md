# 博弈论

**博弈论**研究多个参与者相互影响的决策：每个人的收益同时取决于自己的选择和其他人的选择。

本目录按模型要素、分析方法和适用条件整理概念。正文使用简单收益表、短步骤和计算例子；各项结论与其假设一起阅读。

## 1. 入门与建模

[[读书笔记/博弈论/博弈论全书导读|博弈论基础与阅读路线]]介绍参与者、策略、收益、信息结构和通用分析流程。

基本建模顺序：确定参与者与策略 → 明确收益 → 标注行动顺序和可见信息 → 求最优回应 → 验证均衡及适用条件。
