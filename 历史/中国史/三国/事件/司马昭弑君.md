# 司马昭弑君

> 260 年

260 年五月，魏帝曹髦不满[[历史/中国史/三国/人物/司马昭]]控制朝政，率宫中宿卫、僮仆等出宫，试图讨伐司马昭。司马昭获王沈、王业告密后组织应对，贾充在南阙一带指挥拦截，成济刺杀曹髦。事件通常称“司马昭弑君”，但司马昭并非亲手杀死曹髦的人。

地点：[[历史/中国史/地点/洛阳]]。皇宫、宫门及通往相府的城内道路构成冲突空间；这是京城皇权与权臣军事控制的直接冲突，不是边境战役。

## 行动与责任

| 人物 | 身份与行动 |
| --- | --- |
| 曹髦 | 魏帝，亲自率人出宫，试图夺回政治权力 |
| [[历史/中国史/三国/人物/司马昭]] | 大将军、实际掌权者，获报后部署应对，事后控制追责及继位安排 |
| 贾充 | 司马昭亲信，现场指挥阻截，催促军士行动 |
| 成济 | 直接持兵器刺杀曹髦者，事后被归罪处死 |
| 陈泰 | 主张追究贾充责任，意见未被采纳 |

《三国志》裴注所引材料与《晋书·文帝纪》都涉及贾充督促、成济行刺的过程；《晋书》还保存司马昭事后的自辩。因此，直接行凶、现场指挥和政治责任应分别说明，不能编写司马昭在场亲手弑帝或已被可靠证实的具体杀帝密令。

[[历史/中国史/三国/事件/高平陵之变]]及[[历史/中国史/三国/事件/淮南三叛]]后的司马氏专权，并未消除曹魏皇帝的反抗。曹髦死后，曹奂被立为帝，司马昭继续掌权，后来主持[[历史/中国史/三国/事件/蜀汉灭亡]]的战争；其子司马炎完成[[历史/中国史/三国/事件/西晋代魏]]。
