# 诸葛瑾致书刘备

> 221 年，刘备东征孙权之际。

孙权求和，诸葛瑾向刘备致书，以关羽与汉献帝、荆州与天下、孙权与曹氏的轻重关系为论据，试图劝其改变东征决策。刘备没有因此停止战争，双方继续发展为夷陵战场上的对抗。

| 人物 | 身份与行动 | 对应地点 |
| --- | --- | --- |
| [[历史/中国史/三国/诸葛瑾]] | 孙权臣属，致书劝和 | 史传未明确记载写信或交信城市 |
| [[历史/中国史/三国/刘备]] | 蜀汉皇帝、东征决策者 | 书信提到其军已到白帝，不能据此确定会面地点 |
| [[历史/中国史/三国/孙权]] | 吴方求和决策者 | 吴方军政体系，非书中记载的当面会谈参与者 |
| [[历史/中国史/三国/诸葛亮]] | 诸葛瑾之弟，任职蜀汉 | 亲属关系不等于共同执行此次劝和 |

地点：《诸葛瑾传》没有说明此次致书的准确地点，不能写成“在成都当面求和”。信中提及[[历史/中国史/白帝城|白帝]]，是刘备军到达的消息，不是会面地点的直接证据。

215年诸葛瑾曾奉命出使刘备、与诸葛亮公开相见，那次使行和221年的书信劝和属于不同事件。吴蜀复交通好又是夷陵战后的下一阶段，见[[历史/中国史/三国/吴蜀重建联盟]]。
