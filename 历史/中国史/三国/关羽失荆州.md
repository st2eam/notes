# 关羽失荆州

> 219 年

219年关羽北攻襄樊，击败于禁援军，但曹仁守住樊城，徐晃后续解围。与此同时，孙权命吕蒙进取刘备集团的荆州后方，公安、江陵相继失守。关羽回军后部众离散，退往麦城，突围时被孙权部将擒杀。

| 人物 | 身份与行动 | 对应地点 |
| --- | --- | --- |
| [[历史/中国史/三国/关羽]] | 刘备集团荆州将领，先北攻、后撤退 | [[历史/中国史/襄阳]]、樊城至麦城 |
| [[历史/中国史/三国/孙权]] | 决定夺取关羽后方 | 吴方军政中枢及后续战区 |
| [[历史/中国史/三国/吕蒙]] | 隐蔽进军，接收降城，安抚军民 | 公安、[[历史/中国史/江陵]] |
| [[历史/中国史/三国/陆逊]] | 配合进取西部县地、阻断关羽归路 | 宜都、夷陵等方向 |
| 士仁、麋芳 | 分守公安、江陵，后投降 | 各自守城，不是北攻樊城的援将 |
| 潘璋、朱然及潘璋部下马忠 | 奉命断道，马忠擒获关羽 | 临沮、章乡等突围沿线 |

地点：荆州是历史州域；襄樊为北线战场，公安、江陵为后方城池，麦城为败退据点，临沮相关地区为被擒地点，不能简单写成在麦城内被杀。

结果是刘备集团失去其控制的荆州地盘，不是整个[[历史/中国史/荆州]]都归孙权，曹操仍掌握北部地区。刘备由荆益两路进取的条件受损，后续东征发展为[[历史/中国史/三国/夷陵之战]]。吕蒙取江陵与徐晃解樊城之围分属关羽后方、前线两个方向，共同影响其撤退条件。
