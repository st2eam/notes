# 王建（前蜀）

唐末蜀地将领，907年在成都称帝建立前蜀；与同名的高丽开国君主区别。

## 与时间线有关的活动

- 前 221 年：王贲受齐王建降，秦王嬴政统一六国称始皇帝，行郡县、书同文车同轨。
- 319 年：刘曜于长安改汉为前赵，石勒在襄国称赵王建后赵，汉赵分裂。
- 335 年：石虎迁后赵都城至邺；慕容皝据辽东棘城，337年称燕王建前燕。
- 351 年：略阳氐帅苻洪子苻健率部自枋头西入潼关克长安，称天王建立前秦。
- 698 年：粟末靺鞨大祚荣于东牟山立震国，后受唐封渤海郡王建渤海国。
- 895 年：李克用入关中讨李茂贞，王建据蜀、杨行密据淮南，藩镇割据成型。
