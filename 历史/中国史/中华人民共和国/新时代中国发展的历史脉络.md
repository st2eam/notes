# 新时代中国发展的历史脉络

2012 年以来，中国在改革开放基础上推进现代化建设，经济发展、社会治理与生态文明建设进入新的阶段。

## 背景与发展线索

- 中共十八大后，中国特色社会主义进入新时代，经济发展方式调整、社会治理和生态文明建设受到重视。
- 全面深化改革涉及经济、政治、文化、社会和生态文明等领域；一带一路倡议促进国际合作，同时需放在各参与方实践中考察。
- 脱贫攻坚与全面建成小康社会，是这一阶段的重要任务。2020 年完成脱贫攻坚目标任务，2021 年宣告全面建成小康社会。
- 习近平新时代中国特色社会主义思想形成并发展。考察这一时期应区分已发生事件、政策目标和未来规划。
