# 刘邦

汉朝开国皇帝，楚汉战争后即帝位，先后以洛阳、长安为都；异姓王与中央权力关系是汉初的重要议题。

## 与时间线有关的活动

- 前 206 年：子婴降刘邦，秦亡；鸿门宴后项羽分封十八诸侯，楚汉争霸开启。
- 前 203 年：楚汉久持后“鸿沟议和”中分天下，刘邦旋毁约东追项羽。
- 前 202 年：韩信等垓下十面埋伏灭项羽，汉高祖刘邦称帝定都长安。

以上各项是上游里程碑对其活动的摘要。任官、作战与即位属于不同身份阶段，具体年份的异同以各事件笔记中的对读说明为准。
