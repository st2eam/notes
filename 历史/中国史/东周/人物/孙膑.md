# 孙膑

战国齐国军事人物，桂陵、马陵等战役的谋划者，相关记载见于史记孙子吴起列传。

## 与时间线有关的活动

- 前 353 年：桂陵之战：齐孙膑、田忌“围魏救赵”，大破庞涓。
- 前 341 年：马陵之战孙膑射杀庞涓；商鞅收河西，魏迁大梁。

以上各项是上游里程碑对其活动的摘要。任官、作战与即位属于不同身份阶段，具体年份的异同以各事件笔记中的对读说明为准。
