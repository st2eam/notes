# 朱棣

明成祖，原为燕王，发动靖难之役夺取皇位，迁都北京并支持郑和远航。

## 与时间线有关的活动

- 1399 年：燕王朱棣于北平起兵发动“靖难之役”。
- 1402 年：靖难军破南京朱棣即位为明成祖，选解缙等入值文渊阁创内阁制。
