# 宇文泰

西魏实际掌权者，经营关陇军政组织，与高欢东魏集团对峙。

## 与时间线有关的活动

- 534 年：魏孝武帝西奔长安依宇文泰，高欢立孝静帝迁都邺城，北魏分裂为东西魏。
- 537 年：沙苑之战：宇文泰以少胜多破高欢，创西魏府兵制。
- 550 年：高洋迫东魏禅让建北齐；西魏宇文泰设八柱国十二大将军，关陇集团成型。
- 557 年：陈霸先诛王僧辩掌梁政，受禅建陈；宇文泰子宇文觉代西魏建北周。

以上各项是上游里程碑对其活动的摘要。任官、作战与即位属于不同身份阶段，具体年份的异同以各事件笔记中的对读说明为准。
