# 柳宗元

**柳宗元**：773—819 年；唐代。字子厚，河东人，世称柳河东；因任柳州刺史，也称柳柳州。

后世列为[[历史/中国史/唐宋八大家|唐宋八大家]]之一。

## 生平事件

- **773 年**：出生于官宦家庭，早年接受经史教育。
- **793 年**：[[历史/中国史/唐/柳宗元进士及第|柳宗元进士及第]]，后历集贤殿书院正字、监察御史里行等职。
- **805 年**：[[历史/中国史/唐/柳宗元参与永贞革新遭贬|柳宗元参与永贞革新遭贬]]，由礼部员外郎贬永州司马。
- **805—815 年**：[[历史/中国史/唐/柳宗元谪居永州与文学创作|柳宗元谪居永州与文学创作]]，写作山水游记、寓言及论说，寄托遭际并观察社会。
- **815—819 年**：[[历史/中国史/唐/柳宗元任柳州刺史|柳宗元任柳州刺史]]，兴学并救助因债务而陷为奴婢者。
- **819 年**：病逝柳州任所。

## 代表作品与文学成就

- **《永州八记》**：包括《始得西山宴游记》《至小丘西小石潭记》（通称《小石潭记》）等，将景物描写与个人感受相结合。
- **《捕蛇者说》《封建论》**：分别关注赋税之害、讨论分封与郡县制度；《黔之驴》等寓言善用形象寄寓讽谕。
- **诗歌成就**：《江雪》等语言凝练，意境清峭，与其散文共同构成重要文学遗产。

## 文学史地位与影响

- 与[[历史/中国史/唐/韩愈|韩愈]]并为唐代[[历史/中国史/古文运动|古文运动]]代表；散文兼擅山水游记、寓言和政论，并非仅以游记名世。
- 其山水散文把景物、情感与思想融为一体，对后世游记发展影响深远。
