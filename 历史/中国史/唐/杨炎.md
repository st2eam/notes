# 杨炎

**年代**：727—781 年。字公南，唐德宗时期宰相。

杨炎在[[历史/中国史/长安]]参与中枢政务，780 年提出并推动[[历史/中国史/唐/两税法施行]]，由[[历史/中国史/唐/唐德宗]]批准实施。

两税法适应租庸调、户籍与土地制度长期变化，将主要赋税整合为夏秋征收，并改变课税依据。杨炎是关键推动者，改革却有既存地方实践与制度变化作为基础，不是凭空创造全新征税体系。

781 年，杨炎在政治斗争中被贬并遭赐死；其身后两税法仍延续发展，见[[历史/中国史/唐/唐代赋税制度]]。
