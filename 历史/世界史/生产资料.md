# 生产资料

在马克思主义政治经济学中，生产资料是劳动资料与劳动对象的合称。劳动资料包括工具、机器等劳动所借助的条件；劳动对象是劳动作用于其上的材料或对象，例如纺织生产中的棉花。

判断某件物品是否属于生产资料，要看它在具体生产过程中的用途。例如，供个人穿着的衣服是生活消费品，纺织厂用于生产衣料的机器则是生产资料。

在工人阶级的概念中，关键在于劳动者能否凭借所占有的生产条件独立维持生计，不能把“没有生产资料”简单理解成“没有任何个人财产”。
