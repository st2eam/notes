# 拿破仑

拿破仑·波拿巴（1769—1821），法国军事家、政治家，1799 年政变后出任第一执政，1804 年成为法兰西人的皇帝，史称拿破仑一世。1814 年首次退位，1815 年重返法国建立[[历史/世界史/欧洲/法国/事件/百日王朝|百日王朝]]，失败后再次退位。

## 生平与权力变化

| 时期 | 主要活动 |
| --- | --- |
| 1769 年 | 出生于科西嘉岛阿雅克肖 |
| 法国大革命时期 | 以军官身份崭露头角，通过军事胜利积累声望与政治资本 |
| 1799 年 | 发动雾月政变，建立执政府并出任第一执政 |

| 1812 年 | 远征俄国遭受灾难性损失 |
| 1813 年 | 莱比锡战役失败，欧洲大陆霸权进一步瓦解 |
| 1814 年 | 联军进入巴黎后退位，被流放到厄尔巴岛 |
| 1815 年 | 返回法国恢复帝位，在滑铁卢失败后第二次退位，被流放到圣赫勒拿岛 |
| 1821 年 | 5 月 5 日死于圣赫勒拿岛 |

## 革命遗产与帝国统治

拿破仑的崛起建立在[[历史/世界史/欧洲/法国/事件/法国大革命爆发|法国大革命]]造成的制度与社会变化之上。他巩固了部分革命成果，同时加强行政集权与个人权力。

[[历史/世界史/欧洲/法国/事件/拿破仑法典颁布|1804 年《法国民法典》]]统一民事法律，保护财产权、契约与法律上的公民平等，也保留父权等限制。法典的长期影响与皇帝个人统治的合法性，是两个不同问题。

帝国通过战争扩大影响，但持续作战也消耗兵员和财政，引发反抗与列强联合。军事胜利能够增强其政治权威；连续失败则削弱了支撑个人统治的联盟。

## 与百日王朝的关系

1815 年拿破仑离开厄尔巴岛后，依靠军队中的声望、部分民众支持及复辟政权的弱点，迅速返回巴黎。但法国社会对战争的疲惫与列强的共同反对，使复位后的政权缺乏稳定条件。

[[历史/世界史/欧洲/跨地区/事件/滑铁卢战役|滑铁卢战役]]使其恢复统治的军事尝试失败，[[历史/世界史/欧洲/跨地区/事件/维也纳会议|维也纳会议]]及其后的安排则体现了列强重建欧洲均势的方向。

厄尔巴岛是 1814 年第一次退位后的流放地，圣赫勒拿岛是 1815 年第二次退位后的流放地，两者不应混同。
