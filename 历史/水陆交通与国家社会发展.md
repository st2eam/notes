# 水陆交通与国家社会发展

交通包括道路、河渠、港口、交通工具与管理制度，既促进交流，也需要持续劳动、资源与治理投入。

## 背景与发展线索

- 秦代驰道和灵渠服务统一国家，汉唐陆路与海路推动商贸和文化传播；张骞、玄奘、鉴真只是长期交通网络中的代表人物。
- 隋唐大运河连接南北经济区域，明代郑和航行体现组织、造船与航海技术；民间海上贸易同样重要。
- 蒸汽机、铁路和轮船扩大运输能力，汽车和航空进一步改变空间距离；晚清民国的技术引入伴随资本、主权和治理问题。
- 现代高速铁路、公路与远洋运输扩大区域联系，也涉及资源消耗、生态保护与公共服务公平。交通能力不能单凭线路长度衡量。
