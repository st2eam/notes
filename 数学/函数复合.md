# 函数复合

函数复合是将一个函数的输出作为另一个函数的输入。给定[[数学/数学函数|函数]] $f: A \to B$ 和 $g: B \to C$，复合函数记作 $g\circ f$：

$$
(g\circ f)(x)=g(f(x)).
$$

计算时先执行右侧的 f，再执行左侧的 g。前一个函数的实际输出必须在后一个函数的定义域内。

## 计算顺序

设 $f(x)=2x$，$g(x)=x+1$，则：

$$
(g\circ f)(x)=2x+1,\qquad (f\circ g)(x)=2x+2.
$$

两种顺序的结果不同，因此函数复合通常不满足交换律。

JavaScript 的嵌套调用遵循同样的顺序：

```js
const double = x => x * 2;
const inc = x => x + 1;

inc(double(3)); // 7：先乘 2，再加 1
double(inc(3)); // 8：先加 1，再乘 2
```

## 返回复合函数

可以用[[计算机/基础/编程概念/高阶函数|高阶函数]]构造复合函数：

```js
function compose(g, f) {
    return x => g(f(x));
}

const doubleThenInc = compose(inc, double);
doubleThenInc(3); // 7
```

这里的 `compose` 仅处理单参数函数。使用多个参数、异步函数或不同返回类型时，需要另行约定参数传递和结果处理方式。

## 组合条件与副作用

例如，$f(x)=x-1$，$g(x)=1/x$。复合后的 $g(f(x))=1/(x-1)$ 必须排除输入 1，否则 f 的输出不在 g 的定义域中。

程序中还需要考虑[[计算机/基础/编程概念/副作用|副作用]]：若函数读取或修改共享状态，结果可能依赖执行顺序和调用次数。使用纯函数时，更容易按数学定义推理组合结果。
