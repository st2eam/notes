# 数学函数

函数是两个集合之间的一种对应关系：对定义域中的每个元素，都指定唯一的输出。记作 $f: A \to B$，其中 A 是定义域，B 是陪域，$f(a)$ 是输入 a 对应的函数值。

输入和输出可以是数、字符串、集合等对象。函数不一定用公式定义，也可以通过表格、分段规则等方式给出。

## 定义域、陪域和值域

| 术语 | 含义 |
|---|---|
| 定义域 A | 允许输入的所有元素 |
| 陪域 B | 定义时指定的输出所属集合 |
| 值域 $f(A)$ | 实际能够得到的所有输出 |

值域包含在陪域中，但不一定等于陪域。例如，$f: \mathbb{R} \to \mathbb{R}$，$f(x)=x^2$ 的定义域和陪域都是实数集，值域却是 $[0,+\infty)$。

定义域也是函数定义的一部分。例如，实数范围内的 $f(x)=1/x$ 通常将定义域设为 $\mathbb{R}\setminus\{0\}$；0 不在定义域内，并不违反“每个输入都有输出”的要求。

## 多个输入

多个输入可以合并成一个有序元组。例如：

$$
f: \mathbb{R}^2 \to \mathbb{R},\qquad f(x,y)=x+100y.
$$

这里的一个输入是数对 $(x,y)$。JavaScript 中可以用两个参数实现对应的计算：

```js
function f(x, y) {
    return x + y * 100;
}

f(3, 2); // 203
```

数学定义规定的是对应关系；代码还受数值表示、参数类型和执行过程的限制。判断程序是否实现了这个函数，需要明确输入范围和结果精度。

## 函数相等

按这里采用的定义，两个函数的定义域、陪域相同，并且每个输入对应的输出都相同时，二者相等。表达式不同并不意味着函数不同：实数范围内的 $x^2$ 与 $x\cdot x$ 定义了相同的函数。
