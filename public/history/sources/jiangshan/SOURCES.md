## 结构与实际统计

`DYNASTY_DATA` 中的时期含起止年、代表年、阶段、事件和聚落。阶段以 `snap` 引用离散地图切片；事件含年份、叙述、地点和坐标，部分带月份、人物和多地点；聚落可含古今名、别名、都城时期和存在时段。文献映射以“时期键:年份”为键，保存书名和卷次，同年多件事可能共享该键。

本项目适配器对上述固定版本实际复算的结果：

| 项目 | 数量 | 口径 |
| --- | ---: | --- |
| 时期 | 18 | `DYNASTY_DATA` 数组 |
| 里程碑事件 | 526 | 各时期 `milestones` 合计 |
| 聚落 | 1763 | 各时期 `settlements` 合计，未按历史地点身份去重 |
| 被引用的快照 ID | 204 | `phases[].snap` 去重；不是对 GeoJSON 文件数量或有效几何的核验 |
| 没有文献映射的里程碑 | 441 | 该事件的时期/年份键不在本次文献表中 |
| 对应多个本地同年候选的里程碑 | 50 | 仅按时期和年代区间匹配的候选，不能自动视为同一事件 |

地图替换另行核验了完整压缩疆域包，并按允许的图层提取：17 个历史时期、204 个阶段/快照、1406 条有效聚落记录、260 个河湖要素。地图覆盖前403年至1948年；聚落按时期计数，同城可在多个时期重复出现。提取的安全子集包含1834个共享几何要素、2186条共享环，包含现代周边国家的地理参照；这些统计不代表历史准确性已经逐一核验。产物清单及摘要见 [地图 manifest](../../jiangshan/manifest.json)。

## 地图来源与许可边界

上游代码和多数自编内容声明采用 GPL-3.0。本目录原始事件、文献及派生引用按 GPLv3 保留来源与许可；适配器由本项目编写，原始数据及处理源码随仓库提供。本记录不重新授权整个笔记仓库。

上游不同图层并非统一许可：政权轮廓起源于 [Historical Basemaps — André Ourednik and contributors](https://github.com/aourednik/historical-basemaps) 并声明 GPL；一级行政区根据历史文献人工重绘，但早期来源记录不完整。本次采用政权与一级区划，保留江山地图、相关上游及 GPLv3 署名。原始说明见固定版本的 [data/atlas/README.md](https://github.com/DeanChensj/jiangshan-map/blob/897b9ad4e987fcface8728ffdfbe33e801a3dbae/data/atlas/README.md)。

CHGIS/Hartwell 衍生府级边界明确排除在 GPL 之外，限制学术、非商业并禁止再分发；现代省界适用 DataV GeoAtlas 条款。本次不发布府级层、现代省界或包含这些层的完整压缩包。河湖和周边国家从上游地理数据中提取，仅保留独立的允许子集；周边国家是现代地理参照，不表示历史边界。

阶段区间遵循上游的切换口径：边界年属于后一个阶段/时期，最晚至1948年，无零年。聚落遵循出现/消失年份（出现年包含、消失年不包含）、古名变化和分段都城时期。关联地点通过古今名和已有别名匹配；同名多坐标要求选择，无匹配时显示缺失，不回退到旧数据或用邻近坐标猜测。

[旧地图资源](../../../geo/SOURCES.md)保留归档及原有许可记录，侧栏和事件地图不再加载。上游历史轮廓经过0.01度概化与人工修订，表示阶段示意，不是逐年精确边界；聚落代表点也不等于古址或事件发生点的精确定位。世界其他地区、前403年以前及1949年以后没有额外补入旧来源。

## 处理与复现

文献处理工具：仓库内 `scripts/history/jiangshan.mjs`。运行时产物：`.vitepress/vault/history-references.mjs`；完整候选与缺口报告：`.vitepress/reports/jiangshan-audit.json`，该报告不作为运行时事件库。

地图处理工具：`scripts/history/jiangshan-map.mjs`，只读取语法树中的 JSON 常量，按图层引用筛选几何，再独立解码 VLQ 坐标、闭环并统一 RFC 7946 外环逆时针/内环顺时针。不会执行上游 IIFE 或导出脚本。离线复现输入为 [source-subset.json](../../jiangshan/source-subset.json) 和本目录归档的 `map_data.js`；子集不包含府级引用、府级独占几何及现代省界。地图 GeoJSON、聚落与阶段目录的 SHA-256 均列于 manifest。

```sh
# 离线重算并校验所有地图产物
node scripts/history/jiangshan-map.mjs
# 从已保存的允许子集重新生成
node scripts/history/jiangshan-map.mjs --write
# 重新提取：两个原始文件应分别下载到各自新建的空目录，工具会检查固定 SHA-256
node scripts/history/jiangshan-map.mjs --atlas /path/to/atlas_snapshots.js --geography /path/to/china_geo_data.js --write
```

原始文件固定下载链接及摘要记录于地图 manifest，下载内容不作为运行时网页脚本。完整混合许可包只用于临时提取，不进入发布目录。

在仓库根目录执行：

```sh
# 校验固定摘要、重算并比较产物，不写文件、不联网
node scripts/history/jiangshan.mjs

# 从本地固定来源重建派生引用与审计报告
node scripts/history/jiangshan.mjs --write

# 仅在原始来源缺失时按清单下载；校验 TLS 与 SHA-256，不覆盖不符的已有文件
node scripts/history/jiangshan.mjs --download --write
```

下载的每个文件先进入独立的新空临时目录，校验后复制；解释器不在下载目录运行。上游语法树只允许静态数组、对象和字面量，拒绝函数、调用、展开属性和其他执行语句。来源映射必须通过显式 `historyId` 清单核对；同年匹配仅生成候选。

## 本次改进与剩余范围

| 原有行为 | 本次行为 |
| --- | --- |
| 时间线和地图分别解析日期，公元前世纪排序不一致 | 共享时间解析；前18世纪为前1800—前1701年，修正两处旧排序元数据 |
| 年份筛选只检查事件起始年 | 按年代区间相交检索，支持未注明结束年的“某年起” |
| 地点关键词限于标题、日期和短摘要 | 包含直接关联地点的古今名、别名及笔记地点说明 |
| 侧栏采用旧疆域快照与不同来源的城市坐标 | 全部绘图数据切换至江山地图允许子集，阶段内匹配政权、一级区划、河湖与聚落，支持图层开关及指定年份 |
| 时间线仅链接事件笔记 | 可选择事件并查看其地图、关联地点和来源，原笔记入口保留 |
| 上游资料没有固定版本适配与对应记录 | 归档固定源、验证摘要、保留两组文献线索及完整候选缺口报告 |

世纪初/中叶/末使用约略的十年窗口辅助排序与检索，界面保留原始纪年及近似标记；这些窗口不是经过考证的确切起止日期。年份“起”只确定开始，筛选保留其结束时间未知的语义，地图初始定位在已知起始年。

后续可继续进行逐事件史料核验、世界其他地区及更早/更晚年代的独立数据接入、一级区划逐要素来源补录、地图离线下载和人物行程整理。受限图层需获得对应授权后才能另行处理，不能由本次文献映射或 GPL 声明推定解决。
