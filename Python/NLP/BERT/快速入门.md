# BERT 快速入门

> BERT（Bidirectional Encoder Representations from Transformers）是 Google 在 2018 年提出的预训练语言模型，彻底改变了 NLP 领域。

---

## 1. BERT 是什么？

BERT 的核心思想用两句话概括：

- **预训练**：在海量无标注文本上训练，让模型学会"理解"语言
- **微调**：在下游任务（分类、问答、NER 等）上用少量标注数据精调

### 为什么叫 BERT？

| 字母 | 含义 | 说明 |
|------|------|------|
| **B** | Bidirectional | 双向 — 同时看一个词的左右上下文 |
| **E** | Encoder | 编码器 — 只用了 Transformer 的 Encoder 部分 |
| **R** | Representations | 表示 — 输出词的向量表示 |
| **T** | from **T**ransformers | 基于 Transformer 架构 |

### 与之前模型的区别

| 模型 | 方向 | 特点 |
|------|------|------|
| Word2Vec / GloVe | 静态词向量 | 一个词只有一种向量，不区分上下文 |
| ELMo | 双向 LSTM | 浅层双向，两个方向独立训练 |
| GPT-1 | 单向（从左到右） | 只能看上文 |
| **BERT** | **深度双向** | 同时利用左右上下文 |

## 2. BERT 的两个预训练任务

### 2.1 Masked Language Model (MLM)

随机遮盖 15% 的输入 token，让模型预测被遮盖的词。

```
输入:  今天 [MASK] 很好，适合出去 [MASK]
预测:  今天 天气 很好，适合出去 玩
```

- 被选中的 15% token 中：80% 替换为 `[MASK]`，10% 随机替换，10% 保持不变
- 这样设计是为了减少预训练和微调之间的不匹配

### 2.2 Next Sentence Prediction (NSP)

判断句子 B 是否是句子 A 的下一句。

```
输入:  [CLS] 我喜欢吃苹果 [SEP] 苹果是一种水果 [SEP]
标签:  IsNext

输入:  [CLS] 我喜欢吃苹果 [SEP] 今天天气不错 [SEP]
标签:  NotNext
```

> 注：后来的 RoBERTa 发现 NSP 不是必须的，去掉了这个任务。

## 3. BERT 的输入表示

BERT 的输入由三个 Embedding 相加而成：

```
输入表示 = Token Embedding + Segment Embedding + Position Embedding
```

| Embedding | 作用 |
|-----------|------|
| **Token Embedding** | 词的语义表示，`[CLS]` 开头，`[SEP]` 分隔 |
| **Segment Embedding** | 区分两个句子（句子 A=0，句子 B=1） |
| **Position Embedding** | 表示 token 的位置信息 |

### 特殊 Token

| Token | 位置 | 作用 |
|-------|------|------|
| `[CLS]` | 每句开头 | 汇总整个输入的信息，用于分类 |
| `[SEP]` | 句子之间/末尾 | 分隔两个句子 |
| `[MASK]` | 被遮盖的位置 | MLM 任务中需要预测的 token |

## 5. 快速上手

### 5.1 Pipeline 方式（最简单）

```python
from transformers import pipeline

# 中文填空
unmasker = pipeline("fill-mask", model="bert-base-chinese")
result = unmasker("今天[MASK]气很好")
for r in result:
    print(f"{r['token_str']}: {r['score']:.4f}")
# 预计: 天: 0.9xxx, 空: 0.0xxx
```

### 5.2 文本分类

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

texts = ["这部电影很好看", "这个产品太差了"]
inputs = tokenizer(texts, padding=True, truncation=True, return_tensors="pt")

model.eval()
with torch.no_grad():
    outputs = model(**inputs)
    predictions = torch.argmax(outputs.logits, dim=-1)

print(predictions)
```

### 5.3 获取词向量

```python
from transformers import AutoTokenizer, AutoModel
import torch

model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModel.from_pretrained(model_name)

text = "今天天气真好"
inputs = tokenizer(text, return_tensors="pt")

with torch.no_grad():
    outputs = model(**inputs)

# last_hidden_state shape: (1, seq_len, 768)
last_hidden = outputs.last_hidden_state

# [CLS] 向量作为句子表示
cls_embedding = last_hidden[:, 0, :]       # (1, 768)

# 所有 token 平均作为句子表示
token_mean = last_hidden.squeeze(0).mean(dim=0)  # (768,)
```

### 5.4 句子对相似度

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch.nn.functional as F

model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

a, b = "我喜欢吃苹果", "苹果是我最爱吃的水果"
inputs = tokenizer(a, b, padding=True, truncation=True, return_tensors="pt")

with torch.no_grad():
    probs = F.softmax(model(**inputs).logits, dim=-1)

print(f"相似概率: {probs[0][1]:.4f}")
```

## 6. 微调实战：中文情感分类

### 6.1 准备数据

```python
from datasets import Dataset
from transformers import AutoTokenizer

train_data = {
    "text": [
        "这家餐厅的菜很美味",
        "服务态度太差了",
        "性价比很高，推荐",
        "上菜太慢了，等了一个小时",
        "环境优雅，适合约会",
        "价格贵而且不好吃",
    ],
    "label": [1, 0, 1, 0, 1, 0]  # 1=正面, 0=负面
}

dataset = Dataset.from_dict(train_data)
tokenizer = AutoTokenizer.from_pretrained("bert-base-chinese")

def tokenize_fn(examples):
    return tokenizer(examples["text"], padding="max_length", truncation=True, max_length=128)

tokenized_dataset = dataset.map(tokenize_fn, batched=True)
```

### 6.2 训练

```python
from transformers import (
    AutoModelForSequenceClassification,
    TrainingArguments,
    Trainer,
)
import numpy as np
from sklearn.metrics import accuracy_score, f1_score

model = AutoModelForSequenceClassification.from_pretrained(
    "bert-base-chinese", num_labels=2
)

training_args = TrainingArguments(
    output_dir="./results",
    num_train_epochs=3,
    per_device_train_batch_size=8,
    evaluation_strategy="epoch",
    save_strategy="epoch",
    logging_steps=10,
    load_best_model_at_end=True,
    metric_for_best_model="accuracy",
)

def compute_metrics(eval_pred):
    logits, labels = eval_pred
    preds = np.argmax(logits, axis=-1)
    return {
        "accuracy": accuracy_score(labels, preds),
        "f1": f1_score(labels, preds, average="macro"),
    }

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_dataset,
    eval_dataset=tokenized_dataset,  # 实际应拆分训练/验证集
    compute_metrics=compute_metrics,
)

trainer.train()

# 保存
model.save_pretrained("./my-bert-sentiment")
tokenizer.save_pretrained("./my-bert-sentiment")
```

### 6.3 加载使用

```python
from transformers import pipeline

classifier = pipeline(
    "sentiment-analysis",
    model="./my-bert-sentiment",
    tokenizer="./my-bert-sentiment",
)

print(classifier("这家店真心不错，下次还会来"))
print(classifier("太难吃了，再也不来了"))
```

## 7. BERT 的变体

| 模型 | 改进点 | 中文版 |
|------|--------|--------|
| **RoBERTa** | 更大数据、动态 Masking、去掉 NSP、更大 batch | `hfl/chinese-roberta-wwm-ext` |
| **ALBERT** | 参数共享、嵌入分解，大幅减少参数量 | `voidful/albert_chinese_base` |
| **DistilBERT** | 知识蒸馏，保留 95% 性能，速度提升 60% | — |
| **MacBERT** | MLM 用近义词替代 `[MASK]`，减少预训练-微调差异 | `hfl/chinese-macbert-base` |
| **DeBERTa** | 解耦注意力（内容+位置），增强掩码解码器 | `hfl/chinese-deberta-base` |

## 8. 常见问题

### Q1: BERT 的最大输入长度是多少？

**512 token**。超过会被截断。长文本处理方案：
- 取前 512 token（简单直接）
- 滑动窗口分段处理
- 换用 Longformer、BigBird 等长文本模型

### Q2: `[CLS]` 向量能直接用于语义相似度吗？

可以但不理想。更好的方案：
- 用 **Sentence-BERT**（双塔模型，专门优化相似度）
- 对所有 token 输出做 **mean pooling**
- 中文推荐：`shibing624/text2vec-base-chinese`

### Q3: 预训练 vs 微调？

| 场景 | 推荐 |
|------|------|
| 通用 NLP 任务 | **微调**预训练模型（几千到几万条数据即可） |
| 垂直领域（医疗、法律） | 先**领域继续预训练**，再微调 |
| 从头训练 BERT | ❌ 极不推荐—需要海量数据和算力 |

### Q4: 中文 BERT 效果不好怎么办？

- 确认用了合适的中文模型
- tokenizer 和模型必须匹配
- 学习率建议 `2e-5` ~ `5e-5`，epoch 3~5
- 检查数据标注质量和数量
- 试试哈工大的 RoBERTa 或 MacBERT
