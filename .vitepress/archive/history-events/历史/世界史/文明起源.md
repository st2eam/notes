# 文明起源：从聚落到复杂社会

> 教学范围：约前 5000 年—前 800 年。各地区进入农业社会和城市社会的时间并不相同；“文明”也不应被当作一条所有社会必须走过的单一路径。

先看证据：遗址布局、作物与工具说明人们如何生活；墓葬与大型工程帮助推测社会分工；文字让研究者接近当时的记录，但没有可释读文字的社会并非没有历史。

## 中国线

独立笔记：[[历史/中国史/仰韶文化|仰韶文化]]

<a id="yangshao"></a>
### 仰韶文化

仰韶文化的聚落和彩陶展示了黄河流域的新石器时代生活。它跨越很长时段和不同地区，不能视为单一国家。学习时先区分“考古学文化”与后世的“王朝”。[剑桥大学考古系：仰韶文化](https://www.arch.cam.ac.uk/research/projects/recently-completed-projects/yangshao-culture-100-year-research-history-and)。

独立笔记：[[历史/中国史/良渚古城|良渚古城]]

<a id="liangzhu"></a>
### 良渚古城

良渚位于长江下游，大型城址和水利设施提示较复杂的组织能力。玉器和遗址可以说明社会分层，却无法自动给出当时人的制度名称。[联合国教科文组织遗产说明](https://whc.unesco.org/en/list/1592)。

独立笔记：[[历史/中国史/商王朝|商王朝]]

<a id="shang"></a>
### 商王朝

商代晚期的甲骨文记下占卜及王室活动，青铜器与都城遗址提供另一类证据。两种证据要结合阅读；现存文字更接近王室视角，不能代表所有人的日常生活。

## 世界线

独立笔记：[[历史/世界史/苏美尔城邦|苏美尔城邦]]

<a id="sumer"></a>
### 苏美尔城邦

两河流域出现乌鲁克等城市，早期记账、行政与楔形文字相互关联。城市化不是某一天的发明，也不等同于现代意义上的统一国家。

独立笔记：[[历史/世界史/古埃及早王朝|古埃及早王朝]]

<a id="egypt"></a>
### 古埃及早王朝

尼罗河流域的政治整合、文字与建筑遗存，使古埃及成为研究早期国家的重要案例。尼罗河的环境条件重要，但不能独自解释政治统一。

独立笔记：[[历史/世界史/印度河文明|印度河文明]]

<a id="indus"></a>
### 印度河文明

哈拉帕、摩亨佐-达罗等遗址显示城市规划与交换网络。印度河文字尚未被可靠释读，因此其政治结构和信仰仍有许多不确定之处。
