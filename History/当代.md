# 当代：战争、独立与全球联系

> 教学范围：1914 年至今。这里讨论的是持续变化的历史过程；对较近事件的解释应留意资料更新和不同地区的观点。

两次世界大战、殖民体系瓦解和经济网络扩展塑造了今日世界。本篇以代表节点搭起入门框架，尤其不能把“全球化”看成所有人都同等受益的单向进步。

## 中国线

<a id="may-fourth"></a>
### 五四运动

一战后的巴黎和会处理山东权益问题，引发 1919 年中国的学生抗议及更广泛的社会运动。五四也与思想、语言和文化改革相连，不应只归结为一次外交抗议。

<a id="prc"></a>
### 中华人民共和国成立

1949 年政权更替结束了中国内战的一个阶段，也开启新的国家建设。与亚非去殖民化比较时，要辨明两者的背景和路径，而非把所有战后国家都放入同一模式。

<a id="reform"></a>
### 改革开放

1978 年以后，中国逐步调整经济体制并扩大对外联系。改革与全球贸易增长相互交织，但不同地区、行业和群体受到的影响并不相同。

## 世界线

<a id="wwi"></a>
### 第一次世界大战

战争从欧洲扩展，动员了殖民地和世界各地资源。战后会议改变边界与国际秩序，也与五四运动的直接背景相连。

<a id="wwii"></a>
### 第二次世界大战

这场全球战争在不同地区有不同的起点与进程，亚洲战事早于欧洲的 1939 年节点。战争削弱多个殖民帝国，但战后独立仍取决于各地长期的政治和社会运动。

<a id="decolonization"></a>
### 亚非去殖民化

二战后，亚洲和非洲许多地区争取独立。独立可以通过谈判、抗争或战争实现；政治独立之后，经济与社会关系仍可能延续旧有不平等。

<a id="globalization"></a>
### 全球化加速

20 世纪后期以来，贸易、通信与金融网络更加密集。它是多种历史过程的概括，不代表边界消失，也不代表收益平均分配。
