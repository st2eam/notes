# 早期近代：跨洋联系与帝国

> 教学范围：1500—1800 年。节点所涉政权可能早于这一时间框建立，或在其后继续存在；这里选的是它们与本阶段相关的活动。

航海与跨洋贸易使亚洲、美洲、非洲和欧洲的联系更紧密。这个过程同时包含商品、移民、疾病与暴力；只谈“全球化的开端”会遮蔽被奴役者的经历。

## 中国线

<a id="ming-silver"></a>
### 晚明白银贸易

晚明商品通过马尼拉贸易进入美洲市场，美洲白银经太平洋流向亚洲。它不是“中国只与欧洲直接交易”的故事，菲律宾商人和多地生产者同样重要。[大都会艺术博物馆：马尼拉大帆船贸易](https://www.metmuseum.org/essays/the-manila-galleon-trade-1565-1815)。

<a id="qing"></a>
### 清前期

清朝的建立与边疆扩展改变了中国及内亚政治版图。与南亚莫卧儿帝国对读时，要分别追问统治集团、地方社会与边疆关系，而非把两者归为同一种帝国。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Qing_dynasty)。

<a id="canton"></a>
### 广州贸易体系

18 世纪后期，西方商人在广州的贸易受到特定管理。该制度并不等于清朝与外界完全隔绝：国内市场、亚洲海贸与边疆往来仍在进行。[入门资料：广州体系](https://en.wikipedia.org/wiki/Canton_System)。

## 世界线

<a id="galleon"></a>
### 马尼拉大帆船贸易

1565—1815 年间，马尼拉与阿卡普尔科的航线连接亚洲与美洲，白银和丝绸、瓷器等商品跨洋流动。[大都会艺术博物馆专题](https://www.metmuseum.org/essays/the-manila-galleon-trade-1565-1815)。

<a id="mughal"></a>
### 莫卧儿帝国

莫卧儿帝国在南亚形成广阔统治，并留下行政、艺术和建筑遗产。它的历史不能只用与欧洲殖民者接触的结果来倒推。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Mughal_Empire)。

<a id="atlantic-slavery"></a>
### 跨大西洋奴隶贸易

非洲人被强制掳运至美洲，这是殖民经济的核心暴力之一。研究数字和贸易网络时，也要把被奴役者的抵抗、家庭和文化生命放回叙述。[联合国教科文组织：奴隶之路项目](https://www.unesco.org/en/routes-enslaved-peoples)。

## 怎样对照

晚明与马尼拉大帆船是可追踪的贸易联系。清与莫卧儿适合比较多族群帝国。广州贸易与跨大西洋奴隶贸易同处更大的跨洋世界，但二者制度性质不同；比较不等于把强制劳动说成普通商品交换。
