# 后古典时期：多条商路的世界

> 教学范围：500—1500 年。“后古典”只是本模块的共同时间框，不意味着其他地区都经历了相同的“中世纪”。

这个分期适合从网络入手：陆上丝路、印度洋与跨撒哈拉商路各有参与者、货物和知识流动。政权可以影响通行条件，却不能独自制造全部交流。

## 中国线

<a id="tang"></a>
### 唐王朝

唐都长安连着欧亚商路，宗教、商人和物品从多方向进入。不要把繁荣想象为无障碍的全球贸易：路线会随着战争、税制和地方政治而变化。[联合国教科文组织：丝绸之路](https://www.unesco.org/en/silk-roads/about-silk-roads)。

<a id="xuanzang"></a>
### 玄奘

玄奘赴南亚学习佛教，带回经籍并在唐代从事翻译。他的旅行记录也可用于研究沿途社会，但仍需与其他材料互证。[联合国教科文组织：丝绸之路](https://www.unesco.org/en/silk-roads/about-silk-roads)。

<a id="song"></a>
### 宋代商业与技术

宋代城市、市场、印刷与海上贸易发展。技术传播有复杂路径，不能把某件发明的出现和其在世界各地的使用画成一条简单箭头。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Song_dynasty)。

<a id="yuan"></a>
### 元王朝

元朝由蒙古统治者建立，既属于中国历史，也属于欧亚蒙古诸政权相互作用的历史。讨论此时的商路时，还应看到征服带来的破坏和不同地区的经历。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Yuan_dynasty)。

<a id="ming"></a>
### 明王朝

明朝在元末变局后建立。其后期商品和白银流动连接到跨太平洋贸易；讨论明清更替时，要看到长时间的战争与多方参与。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Ming_dynasty)。

## 世界线

<a id="abbasid"></a>
### 阿拔斯王朝

巴格达的学术、翻译与商业活动联系了多种语言和知识传统。“黄金时代”是概括性称呼，不能抹去不同时期、地区与群体的差异。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Abbasid_Caliphate)。

<a id="mali"></a>
### 马里帝国

马里控制并参与西非与跨撒哈拉商路，廷巴克图成为重要学术中心。它提醒我们：研究世界交流不能只沿欧亚东西轴线展开。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Mali_Empire)。

<a id="mongol"></a>
### 蒙古帝国

蒙古帝国的扩张重组欧亚政治和交通条件，但其统治并非始终统一，也不能用“交流增加”掩盖战争的破坏。[入门资料：维基百科（含参考文献）](https://en.wikipedia.org/wiki/Mongol_Empire)。
