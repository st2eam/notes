# 近现代：工业化与帝国竞争

> 教学范围：1800—1914 年。工业革命始于这一时间框之前，1911 年的政治变革也并未在 1914 年结束；分期边界不是因果边界。

机械化生产、殖民扩张、战争与改革共同改变了 19 世纪的世界。比较时要同时看外部压力与内部社会变化，避免用单一原因解释复杂转折。

## 中国线

<a id="opium"></a>
### 鸦片战争

两次鸦片战争及条约改变了清朝的对外关系。把它放在工业化背景下有帮助，但战争的直接过程还涉及鸦片贸易、外交争端和军事力量差异。

<a id="taiping"></a>
### 太平天国运动

这场长期内战造成巨大人员损失，清朝财政和地方军事结构也受到冲击。不能仅用外部侵略解释它，更要看内部社会与宗教政治动员。

<a id="xinhai"></a>
### 辛亥革命

1911 年革命结束清朝统治，但建立稳定共和政治仍面临诸多难题。把它与明治维新对读，重点是不同的改革条件和政治结果，不能简单判定“谁更成功”。

<a id="sun-yat-sen"></a>
### 孙中山

孙中山长期参与革命组织和共和主张的传播，是辛亥革命的重要人物之一。革命由多地、多群体推动，不能简化为某一人的单独行动。

## 世界线

<a id="industrial"></a>
### 工业革命

机械化、工厂制度和交通技术先在英国等地发展，随后扩展。工业化创造新财富，也带来劳动与环境问题，并改变跨地区的力量关系。

<a id="meiji"></a>
### 明治维新

1868 年起的制度改革改变日本的国家结构和产业发展。改革也伴随对外扩张；学习时不宜只把它写成“现代化模板”。

<a id="africa-partition"></a>
### 瓜分非洲

19 世纪后期欧洲列强加快占领非洲，殖民统治改变边界、土地和劳动关系。非洲社会有自己的政治与抵抗历史，不能只作为欧洲政策的背景板。
