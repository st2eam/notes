# 古典时期：思想与帝国

> 教学范围：前 800 年—公元 500 年。“古典”是便于对读的标签，各地区自己的分期与转折并不一致。

这一时期的比较重点不是“谁先发明帝国”，而是广域政权如何收税、管理地方、修路、调动军队，以及思想传统怎样回应政治秩序。

## 中国线

<a id="zhou"></a>
### 东周与诸子

东周的诸侯竞争与礼制变化，为儒、墨、道、法等不同思想提供了讨论政治和伦理的环境。诸子主张彼此不同，不能合成一种“古代中国思想”。

<a id="qin"></a>
### 秦统一

前 221 年的统一让战国竞争转向帝国治理。郡县、法令与标准化措施有长远影响；秦的统治时间很短，制度的延续还需连同汉代观察。

<a id="han"></a>
### 汉王朝

汉代延续并调整帝国制度。使节、商人和中亚诸政权共同构成了交流网络；“丝绸之路”是后来对多条路线的概括，不是一条由汉朝直接通往罗马的固定道路。[联合国教科文组织：丝绸之路](https://www.unesco.org/en/silk-roads/about-silk-roads)。

<a id="zhang-qian"></a>
### 张骞

张骞受汉武帝派遣出使西域，其行程与报告加深了汉廷对中亚的认识。交流网络由多方参与，不能归功于单一使节。[联合国教科文组织：丝绸之路](https://www.unesco.org/en/silk-roads/about-silk-roads)。

## 世界线

<a id="achaemenid"></a>
### 阿契美尼德帝国

这个西亚帝国通过行省、道路与地方精英维系统治。与东周对读，可以比较分封、地方治理和跨地区交通，但两者的制度背景不同。

<a id="maurya"></a>
### 孔雀王朝

南亚的孔雀王朝留下阿育王敕令等重要材料。把它与秦相比，应分别考察领土、官僚与文本证据，避免仅凭“大一统”给出同一解释。[国家地理教育：孔雀王朝](https://education.nationalgeographic.org/resource/mauryan-empire/)。

<a id="ashoka"></a>
### 阿育王

阿育王是孔雀王朝君主。其敕令是研究统治理念及佛教传播的重要证据，但不能把宣示直接等同于所有地区的实际治理。[国家地理教育：孔雀王朝](https://education.nationalgeographic.org/resource/mauryan-empire/)。

<a id="rome"></a>
### 罗马帝国

罗马帝国的道路、城市和法律连接了地中海周边。与汉代并读有助于提出帝国规模和治理问题；丝路上商品可以经过多次转手，不代表两端政权常有直接往来。
